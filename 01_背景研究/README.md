## 背景研究只做三件事

1. **题目逐句翻译与点透**：把题目每个关键词的字面义和深层含义列出来。
2. **深度钻研**：相关领域背景知识、可复用课题资产清单（算法实现、中文文献等）。
3. **参考文献库**：收集相关论文，建索引。

**不要无限读论文**——背景研究是为建模服务的，够用就停，把时间留给建模。
