## 一、为什么是深度平均 2D

泥石流沿沟道运动，水平尺度（km）远大于垂直尺度（m）；深度平均可以把三维问题降为二维，计算可行，且能给出：

- 流深 `h(x,y,t)`；
- 深度平均速度 `u(x,y,t)`；
- 到达时间/影响范围/堆积。

代价：

- 不能解析垂向速度/浓度分层；
- 冲击力只能用动压 `0.5ρabs(u)²` 近似；
- 参数（μ/ξ/堆积）是等效参数，不是基本物理常数。

**结论**：Q4 用深度平均 2D 是“数据/时间/验证”约束下的合理选择；论文必须写“不是 3D 两相 CFD”。

## 二、为什么不是清水浅水方程

清水浅水只有 `ρ_w`、无屈服应力/高浓度；泥石流密度 1495–1990 kg/m³，且高浓度下有额外阻力/冲击力。用清水会：

- 低估密度/动压；
- 低估或错估摩擦/堆积；
- 把“泥石流”算成“山洪”。

因此至少：

```
ρ = ρ_s C_v + ρ_w(1-C_v)
τ_b = ρgh(μcosθ + abs(u)²/(ξh))
```

**结论**：Q4 的“泥石流”与“山洪”必须分开；清水只作数值验证（Ritter），不作主模型。

## 三、为什么是 Voellmy

Voellmy 阻力：

```
τ_b = ρgh( μcosθ + abs(u)²/(ξh) )
```

- 第一项 `μρghcosθ`：库仑摩擦，控制“停得住/停不住”；
- 第二项 `ρabs(u)²/ξ`：湍流/碰撞，控制高速段的能量耗散；
- 两个参数都有工程/文献范围，可解释、可做敏感性。

相比纯库仑：Voellmy 在高速段阻力随 `u²` 增长，避免“越陡越快、停不下来”；相比 Manning：Voellmy 不依赖 `n` 的经验量纲，更适合泥石流。

**结论**：Voellmy 是主阻力；库仑/Manning 只作对照。

## 四、为什么需要堆积

没有堆积，流体会一直流到边界，影响范围/流深/质量收支都不真实。Q4 用速度阈值堆积：

```
D = c_dep h max(0, 1-abs(u)/u_stop)
```

- 速度低于 `u_stop` 时开始堆积；
- `c_dep` 控制堆积速率；
- 堆积量从 `h` 转到 `b_dep`，质量守恒。

这是工程近似，不是完整沉降理论；标 `[C]`。但它让“堆积/到达”成为可计算量，而不是只看最大范围。

## 五、为什么是 HLL + SSP-RK

- 泥石流方程是双曲守恒律，激波/干湿前沿会出现；
- HLL 近似 Riemann 解，能处理激波/干床，正值性较好；
- SSP-RK2 保持 TVD/稳定性；
- CFL 控制时间步，避免负流深/爆炸。

**命题 1（CFL 必要性）**：显式格式的 `Δt` 必须满足 `Δt ≤ CFL·Δ/(abs(u)+√(gh))`；否则信息在一个步长内跨过多个网格，格式不稳定。

**命题 2（质量守恒）**：若通量边界一致、堆积只做 `h→b_dep` 的转移，则 `ΣhA+Σb_depA+M_out` 守恒（离散误差内）。这是 Q4 的第一验证。

## 六、四类验证的逻辑

### 6.1 质量守恒

检查“有没有凭空产生/丢失质量”。若质量不守恒，后面的流深/范围都不可信。

### 6.2 零动量

平底、静止、无扰动，数值格式不应产生“自流动”。若零动量失败，说明源项/干湿/通量有 bug。

### 6.3 Ritter 溃坝

清水、平底、干床有解析解：

```
x_f(t)=2t√(g h0)
```

它验证**通量/HLL/时间推进**；不验证 Voellmy/堆积（那些没有解析解）。

### 6.4 网格收敛

90/60/30 m 的 `t_arr/h_max/D_impact` 应逐渐稳定；若 30 m 与 60/90 m 差异大，说明结果依赖网格，不能给“精确到达时间”。

**结论**：四类验证分别检查守恒、静止、通量、网格；缺一不可。

## 七、为什么不能反演“最优参数”

2026 事件只有一个，且源区/释放体积/浓度/阻力都没有实测。用单事件反演 `μ/ξ/V0`：

- 参数不可识别（多组参数可得同一到达时间）；
- 会把“情景”伪装成“标定”；
- 违反“不伪造真值”的红线。

Q4 只做：

- 参数范围 + 情景矩阵；
- 2026 量级一致性（20+ km、约 7 min）；
- 不写“最优/复现真实灾害”。

## 八、能得出什么、不能得出什么

### 能得出

- 不同 `V0/C_v/μ/ξ` 下的流深/流速/到达时间/影响范围/堆积；
- 质量收支/数值稳定性/网格收敛；
- 与 Q3 的 `T_travel/D_arrival` 情景；
- 防灾情景（检查坝/停淤场）的相对效果。

### 不能得出

- “真实灾害的精确流深/流速”；
- “最优 μ/ξ/V0”；
- “3D 两相流的所有细节”；
- “县级人口精确暴露”；
- “Q4 包络是实测到达范围”。

## 九、与 Q3 的闭环

```
Q3: T_trigger 区间
  ↓
Q4: T_travel 分布 → T_impact = T_trigger + T_travel
  ↓
Q3: T_impact 区间、L=T_impact-T_warn、D_arrival/D_impact
```

Q4 给 Q3 的是**情景分布**，不是单值；Q3 给 Q4 的是**触发情景**，不是“已发生”。两者都是 `[C]` 情景链，论文要写清。
