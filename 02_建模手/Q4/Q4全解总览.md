## 一句话定位

**Q4 = 在 DEM 沟道走廊上构建深度平均二维泥石流/碎屑流仿真：Voellmy 阻力 + 质量守恒 + 速度阈值堆积 + HLL/SSP-RK 数值格式；用释放体积/浓度/阻力情景矩阵给出流深、流速、到达时间、影响范围、堆积厚度；用质量守恒、零动量、Ritter 溃坝、网格收敛四类验证，不把动画当结论。**

不是“清水浅水方程 + 漂亮 3D 动画”，不是“用 0.319 km³ 冰川总体积当释放体积”，也不是“用一个 2026 事件反演出一组“最优参数”。

## 题设逐词点透

> 原文：“构建吉隆泥石流发生的仿真环境，设定明确的关键参数，给出仿真过程及可视化的仿真结果。”

| 词 | 字面 | 点透 |
|---|---|---|
| 仿真环境 | 数值模型 | 深度平均守恒方程 + 地形 + 边界 + 数值格式 |
| 关键参数 | 可追溯 | 释放体积、固相浓度、密度、μ、ξ、初始流深/速度、网格 |
| 仿真过程 | 时间演化 | 启动→传播→堆积/到达；输出 `h/abs(u)/t_arr/影响范围` |
| 可视化 | 结果表达 | 地形/淹没/流速/到达时间/堆积；必须配验证 |
| 仿真结果 | 情景 | 不是“真实灾害复原”；参数未标定要标 `[C]` |

**点透结论**：Q4 的分数在**控制方程、参数表、数值验证、过程量**，不在渲染。先保证“守恒、稳定、可复现”，再谈可视化。

## 模型选择

| 选项 | 决定 | 理由 |
|---|---|---|
| 3D 两相 CFD | ❌ 不用 | 数据/时间不够；无法验证 |
| 清水浅水 | ❌ 不用 | 低估密度/屈服应力/冲击力 |
| 深度平均 2D 泥石流 | ✅ 主模型 | 沟道约束、计算可行、可验证 |
| Voellmy 阻力 | ✅ 主阻力 | 摩擦+湍流两项，参数可解释 |
| 库仑/Manning | 🟡 对照 | 敏感性/对照，不作主模型 |
| 侵蚀/夹带 | 🟡 情景 | 无侵蚀数据；基线 `E=0`，情景开 |
| 速度阈值堆积 | ✅ 主堆积 | 可守恒、可解释；参数情景 |
| 3D 可视化 | ✅ 表达 | 只作表达，不替代验证 |

## 方法路线图

```
DEM + 主沟中心线
  ↓ 走廊提取（±1.5 km，30 m）
初始源区：V0、A_source、h0、C_v、ρ
  ↓
2D 深度平均方程：
  ∂h/∂t + ∇·(hu) = -D
  ∂(hu)/∂t + ∇·(huu + 0.5gh²) = -gh∇b - τ_b/ρ
  τ_b = ρgh(μcosθ + abs(u)²/(ξh))
  ↓ HLL + SSP-RK2 + CFL + 湿干处理
  ↓ 速度阈值堆积 D；b_dep 累积
输出：h(x,y,t)、abs(u)、t_arr、max h、max abs(u)、影响范围、b_dep
  ↓
验证：质量守恒 / 零动量 / Ritter 溃坝 / 网格收敛
  ↓
情景矩阵 + 2026 案例一致性 + Q3 回填
  ↓
可视化：地形/淹没/流速/到达时间/堆积/剖面
```

## 关键参数（情景，不是标定值）

| 参数 | 范围 | 说明 |
|---|---|---|
| `V0` 释放体积 | 1e5–1e6 m³ | **不是 0.319 km³ 冰川总冰量** |
| `A_source` 源区面积 | 1e4–1e5 m² | 由源区多边形/沟头给定 |
| `h0=V0/A_source` | 1–20 m | 初始堆积深度 |
| `C_v` 固相体积浓度 | 0.3–0.6 | 密度 `ρ=ρ_s C_v+ρ_w(1-C_v)` |
| `ρ_s/ρ_w` | 2650/1000 kg/m³ | 密度 1495–1990 |
| `μ` Voellmy 摩擦 | 0.05–0.3 | 沟道/坡面 |
| `ξ` 湍流系数 | 100–1000 m/s² | 速度平方阻力 |
| `u_stop` 堆积阈值 | 0.5–2 m/s | 速度阈值堆积 |
| `c_dep` 堆积速率 | 0.01–0.1 s⁻¹ | 情景 |
| `h_arr` 到达阈值 | 0.2 m | 到达时间 |
| `h_impact` 影响阈值 | 0.5 m | 影响范围 |
| 网格 | 90/60/30 m | 30 m 走廊基线；收敛对比 |
| CFL | 0.3 | 显式稳定 |

---

## 验证（比动画重要）

1. **质量守恒**：`M(t)=ΣhA+Σb_dep A+outflow`，相对误差 <1%。
2. **零动量**：平底、静止、无扰动，100 步后 `max abs(u)<1e-6`，`h` 不变。
3. **Ritter 溃坝**：清水、平底、干床，前沿 `x_f=2t√(gh0)`，误差 <5–10%。
4. **网格收敛**：90/60/30 m 的到达时间/最大流深/影响范围，相对差 <10–15%；不收敛就报“未收敛”。
5. **参数敏感性**：`V0/μ/ξ/C_v` 端点；给范围，不给“最优”。
6. **2026 案例一致性**：20+ km、官方约 7 min；仿真给量级/情景，不反演“真值”。

## 输出与可视化

| 输出 | 含义 |
|---|---|
| `h(x,y,t)` | 流深场 |
| `abs(u)(x,y,t)` | 流速场 |
| `t_arr(x,y)` | 首次 `h≥h_arr` 的到达时间 |
| `h_max(x,y)` | 最大流深 |
| `u_max(x,y)` | 最大流速 |
| `D_impact` | `h≥h_impact` 的最远距离/面积 |
| `b_dep(x,y)` | 堆积厚度 |
| 质量收支表 | 初始/流出/堆积/残差 |
| 剖面/时间序列 | 沟道关键点 `h/abs(u)` 随时间 |

**可视化**：地形晕渲 + 淹没/流速/到达时间/堆积；3D 只作表达；每张图配参数、网格、验证状态。

## 创新点

1. **守恒型 2D 泥石流仿真**：不是清水；Voellmy + 速度阈值堆积；质量收支可审计。
2. **四类验证**：质量守恒/零动量/Ritter/网格收敛；比“漂亮动画”更能说服评委。
3. **情景矩阵**：`V0/C_v/μ/ξ` 范围，不把单次事件反演当“最优参数”。
4. **Q3 闭环**：`T_travel/D_arrival/D_impact` 回填 Q3，形成“触发→传播→预警”链。
5. **防灾情景**（P1）：检查坝/停淤场/拓宽，比较流深/到达/影响，不停留在“自然演进”。
