## 二、控制方程

### F1 质量

```
∂h/∂t + ∂(hu)/∂x + ∂(hv)/∂y = -D
```

基线 `E=0`；开侵蚀时右端 `E-D`。

### F2 x 动量

```
∂(hu)/∂t + ∂(hu² + 0.5 g h²)/∂x + ∂(huv)/∂y
    = -g h ∂b/∂x - τ_bx/ρ
```

### F3 y 动量

```
∂(hv)/∂t + ∂(huv)/∂x + ∂(hv² + 0.5 g h²)/∂y
    = -g h ∂b/∂y - τ_by/ρ
```

### F4 Voellmy 阻力

```
τ_b = ρ g h ( μ cosθ + abs(u)²/(ξ h) )
cosθ = 1/√(1+|∇b|²)
τ_bx = τ_b u/abs(u),  τ_by = τ_b v/abs(u)
```

### F5 密度

```
ρ = ρ_s C_v + ρ_w (1-C_v)
```

### F6 速度阈值堆积

```
D = c_dep · h · max(0, 1 - abs(u)/u_stop),  abs(u)<u_stop
D = 0,                                    abs(u)≥u_stop
h ← h - DΔt,  b_dep ← b_dep + DΔt,  b ← b + DΔt
```

限制 `DΔt ≤ 0.5h`。

## 三、数值

### F7 CFL

```
Δt = CFL · Δ / max(abs(u)+√(g h)),  CFL=0.3
```

### F8 HLL 通量

```
S_L = min(u_L·n - √(g h_L), u_R·n - √(g h_R))
S_R = max(u_L·n + √(g h_L), u_R·n + √(g h_R))
F_HLL = (S_R F_L - S_L F_R + S_L S_R (U_R-U_L)) / (S_R-S_L)
```

### F9 源项分裂

```
U* = U^n + Δt·L_flux(U^n)
U^{n+1} = U* + Δt·(S_bed + S_fric + S_dep)
```

阻力可用半隐式；底坡中心差分；堆积按 F6。

## 四、输出

### F10 到达时间

```
t_arr(x,y) = min{ t : h(x,y,t) ≥ h_arr },  h_arr=0.2 m
```

### F11 影响范围

```
D_impact = max{ s : h(s,t) ≥ h_impact },  h_impact=0.5 m
```

可按沿程距离/面积两种口径；论文写清。

### F12 质量误差

```
M(t) = Σ h A + Σ b_dep A + M_out(t)
ε_M = |M(t)-M(0)| / M(0)
```

### F13 初始流深

```
h0 = V0 / A_source
```

### F14 Ritter 前沿

```
x_f(t) = 2 t √(g h0)
```

### F15 网格收敛

```
ε_g = |R_g - R_30| / R_30
```

`R`：到达时间/最大流深/影响范围。

### F16 动压（影响强度）

```
p_dyn = 0.5 ρ abs(u)²
```

用于影响强度/承灾体讨论；不是静压。
