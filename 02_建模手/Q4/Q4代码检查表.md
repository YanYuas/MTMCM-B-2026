## 四、Ritter 溃坝：为什么用 L1，不用“前端”

- 解析前沿 `x_f=2t√(gh0)`；
- 一阶 HLL 在干湿前沿有数值扩散，**前端阈值法**（`h>0.01`）会出现“粗网格前端超射、细网格前端滞后”的非单调现象；
- 因此主判据用**剖面 L1 误差**：

```
L1 = mean(|h_sim(x)-h_anal(x)|)/h0
```

| dx | L1 | L2 | 前端误差（诊断） |
|---:|---:|---:|---:|
| 20 | 0.0115 | 0.0258 | 0.060 |
| 10 | 0.0081 | 0.0187 | 0.066 |
| 5 | 0.0056 | 0.0132 | 0.129 |

**判读**：L1 随 dx 减小单调下降；前端误差非单调，不能作为唯一判据。论文写“L1 收敛；前端阈值法仅诊断”。

## 五、2D 集成检查（编程手必须另跑）

组件级 10/10 不等于 2D 正确；2D 还要过：

| 检查 | 方法 | 门槛 |
|---|---|---|
| 零动量 2D | 平底、`h=1`、`u=v=0`、闭合边界，100 步 | `max abs(u)<1e-6` |
| 质量守恒 2D | 闭合域，无流入/流出，初始 `V0` | `ε_M<1%` |
| 质量收支 2D | 开放下游，`ΣhA+Σb_depA+M_out` | `ε_M<1%` |
| Ritter 2D 槽 | 1D 渠道（宽 3–5 格），干床 | L1 随 dx 下降；前端误差 ≤15% |
| 网格收敛 | 90/60/30 同参数 | `ε_g<15%` 或写“未收敛” |
| 正值性 | 全场扫描 | 无 `h<0`/NaN |
| CFL | 每步 `dt≤0.3Δ/(max abs(u)+√(gh))` | 无爆炸 |
| 堆积质量 | `h→b_dep` | `Σh+Σb_dep` 守恒 |
| 情景 | S0–S11 | 参数/输出完整 |

## 六、怎么把 2D 结果对到本表

1. **HLL**：直接把你的 `hll_flux` 对 `q4_hll_cases.csv`；
2. **Ritter**：在 2D 求解器里建一条 1D 槽（宽 3–5 格、两侧闭合），初始 `h0=10`、干床、平底；在 `t=10s` 输出中心线 `h(x)`，与本表 `q4_ritter_profile_dx5.csv` 的 `h_anal` 比 L1；
3. **零动量**：平底、闭合、`h=1`、`u=v=0`；100 步后 `max abs(u)`；
4. **质量**：闭合域/开放域两种；开放域必须记录 `M_out`；
5. **网格**：30/60/90 同源区/同参数；输出 `t_arr/D_impact/h_max`。

## 八、常见错

1. HLL 均匀态没有退回物理通量 → 波速/通量公式错。
2. CFL 用 `max(h)` 而不是 `max(abs(u)+√(gh))` → 时间步过大。
3. 前端阈值法判收敛 → 粗网格超射/细网格滞后，误判“不收敛”。
4. 质量收支漏 `M_out`/`b_dep` → 误差 >1%。
5. 堆积 `DΔt` 未限制 → `h<0`。
6. 2D 槽两侧开放 → 质量流失，Ritter 对不上。
7. 网格三套参数不一致 → 假收敛。
8. 把 1D 参考解当 2D 真实结果 → 过度声明。
