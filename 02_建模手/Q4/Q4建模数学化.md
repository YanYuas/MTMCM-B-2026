## 一、仿真域与网格

- **域**：主流路中心线两侧各约 1.5 km 的走廊；全 DEM 只作底图/可视化。
- **网格**：90/60/30 m 三套；30 m 为基线；`dx=dy=Δ`。
- **单元**：`(i,j)`；底高程 `b_{ij}`；流深 `h_{ij}`；深度平均速度 `(u_{ij},v_{ij})`。
- **干湿**：`h_min=0.05 m`；`h<h_min` 视为干，速度置 0。
- **源区**：沟头/源区多边形；初始体积 `V0`，面积 `A_source`，`h0=V0/A_source`。
- **边界**：上游/两侧闭合（法向通量 0）；下游开放（允许流出，计入质量收支）。

## 二、控制方程

### 2.1 质量

```
∂h/∂t + ∂(hu)/∂x + ∂(hv)/∂y = -D
```

`D≥0` 为堆积/沉积汇；基线 `E=0`（不侵蚀）。若开侵蚀 `E`，右端为 `E-D`。

### 2.2 动量

```
∂(hu)/∂t + ∂(hu² + 0.5 g h²)/∂x + ∂(huv)/∂y
    = -g h ∂b/∂x - τ_bx/ρ

∂(hv)/∂t + ∂(huv)/∂x + ∂(hv² + 0.5 g h²)/∂y
    = -g h ∂b/∂y - τ_by/ρ
```

`g=9.81 m/s²`；`ρ` 为混合物密度；`τ_bx=τ_b u/abs(u)`，`τ_by=τ_b v/abs(u)`。

### 2.3 Voellmy 阻力

```
τ_b = ρ g h ( μ cosθ + abs(u)²/(ξ h) )
cosθ = 1/√(1+|∇b|²)
```

- `μ`：摩擦系数（0.05–0.3）；
- `ξ`：湍流/速度平方系数（100–1000 m/s²）；
- 第一项摩擦、第二项湍流；不是 Manning，也不是纯库仑。

### 2.4 密度

```
ρ = ρ_s C_v + ρ_w (1-C_v)
```

`ρ_s=2650`、`ρ_w=1000 kg/m³`；`C_v∈[0.3,0.6]` → `ρ∈[1495,1990]`。

### 2.5 速度阈值堆积

```
D = c_dep · h · max(0, 1 - abs(u)/u_stop),   若 abs(u)<u_stop
D = 0,                                     若 abs(u)≥u_stop
```

- `c_dep∈[0.01,0.1] s⁻¹`；`u_stop∈[0.5,2] m/s`；
- 限制 `D·Δt ≤ 0.5 h`，避免负流深；
- 更新：`h ← h - DΔt`，`b_dep ← b_dep + DΔt`，`b ← b + DΔt`；
- 质量守恒：流深减少 = 堆积增加。

> 这是“速度阈值”工程堆积模型，不是完整固液两相沉降理论；标 `[C]`。

## 三、初始/边界条件

### 3.1 初始源区

```
h(x,y,0) = h0,  (x,y)∈A_source
h(x,y,0) = 0,   其他
u(x,y,0)=v(x,y,0)=0
```

`h0=V0/A_source`；`V0=1e5–1e6 m³`；`A_source=1e4–1e5 m²`。

### 3.2 边界

- 上游/两侧：`hu·n=0`（闭合）；
- 下游：开放边界，允许 `hu·n>0` 流出；记录 `M_out`；
- 不放入射边界（避免“源源不断”的虚假质量）。

### 3.3 2026 案例

- 源区高海拔（约 5200 m），源区面积/体积情景；
- 不把 0.319 km³ 冰川总冰量当 `V0`；
- 官方 20+ km、约 7 min 只作**量级一致性**，不反演参数。

## 四、数值格式

### 4.1 有限体积

单元守恒量 `U=(h,hu,hv)^T`；界面通量 `F(U)`；半离散：

```
dU_{ij}/dt = -(F_{i+1/2,j}-F_{i-1/2,j})/Δ - (G_{i,j+1/2}-G_{i,j-1/2})/Δ + S_{ij}
```

`S` 包括底坡、Voellmy 阻力、堆积。

### 4.2 HLL 通量

法向 `n`，左右状态 `U_L,U_R`：

```
S_L = min(u_L·n - √(g h_L), u_R·n - √(g h_R))
S_R = max(u_L·n + √(g h_L), u_R·n + √(g h_R))
F_HLL = (S_R F_L - S_L F_R + S_L S_R (U_R-U_L)) / (S_R-S_L)
```

- 干单元：若两侧均干，通量 0；若一侧干，按干床 HLL 处理；
- 2D 用 x/y 方向扫描；切向速度迎风/中心，论文写清；
- 可选 MUSCL/minmod 二阶重构；基线一阶 HLL 足够验证。

### 4.3 时间推进

```
U^{n+1} = U^n + Δt · L(U^n)          （SSP-RK2 两步）
```

- CFL：

```
Δt = CFL · Δ / max_{ij}( abs(u)+√(g h) ),  CFL=0.3
```

- 每步限制 `h≥0`；`h<h_min` 干化；`abs(u)` 上限（如 60 m/s）防爆；
- 源项算子分裂：先通量，再底坡/阻力/堆积；阻力可用半隐式稳定。

## 六、验证指标

### 6.1 质量守恒

```
M(t) = Σ h A + Σ b_dep A + M_out(t)
ε_M = |M(t)-M(0)| / M(0)
```

要求 `ε_M<1%`（基线）；若开边界流出，必须计入 `M_out`，不能只看域内。

### 6.2 零动量

平底 `b=const`、`h=const`、`u=v=0`；跑 100 步：

```
max abs(u) < 1e-6 m/s；max|h-h0| < 1e-6 m
```

### 6.3 Ritter 溃坝

清水、平底、干床、初始水柱 `h0`；解析前沿：

```
x_f(t) = 2 t √(g h0)
```

比较 `x_f_sim` 与 `x_f_anal`；相对误差 <5–10%。

### 6.4 网格收敛

90/60/30 m 三套，比较：

```
ε_g = |R_g - R_30| / R_30
```

`R` 可取到达时间、最大流深、影响范围；要求 <10–15%；否则写“未收敛”。

### 6.5 参数敏感性

`V0/μ/ξ/C_v` 端点；给范围，不给“最优”。报告 `t_arr/D_impact/h_max` 的变化。
