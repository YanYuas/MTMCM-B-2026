## 二、边界情形

| 情形 | 处理 |
|---|---|
| 源区在走廊外 | 调整走廊/源区；不硬塞 |
| 源区面积过大 | `h0` 过小；检查 `V0/A_source` |
| 全部干 | 不启动；检查源区/地形 |
| 下游流出过大 | 质量收支含 `M_out`；不丢 |
| 负流深 | 限制 `DΔt`；干化；重跑 |
| NaN/Inf | 缩小 `Δt`；检查 CFL/阻力 |
| 网格收敛不过 | 写“未收敛”；不挑最好网格 |
| 2026 到达差很多 | 写“量级不一致”；不调参硬凑 |
| 参数端点爆炸 | 检查 `μ/ξ` 范围；降 `CFL` |
| 可视化像“洪水” | 检查密度/阻力/堆积；不是清水 |
| 县级人口 | 只作背景；不精确到人 |
| 检查坝情景 | 抬高 `b`；不改其他参数 |

## 三、边界情形与论文写法

| 情形 | 写法 |
|---|---|
| 质量误差 >1% | “质量收支未闭合；结果仅作情景” |
| 网格未收敛 | “30/60/90 差异 >15%；到达时间不确定” |
| 2026 量级不一致 | “情景未复现 7 min；不反演参数” |
| 参数敏感 | “给范围；不写最优” |
| 走廊截断 | “走廊边界；不做全城淹没声明” |
| 无实测验证 | “四类数值验证；无实测标定” |
| 堆积近似 | “速度阈值工程近似；标 C” |

## 四、防灾拓展（P1）

1. **检查坝**：在沟道关键位置抬高 `b`，形成障碍；比较上游 `h_max`、下游 `D_impact`、堆积量。
2. **停淤场**：局部拓宽/降低坡度，让 `u<u_stop` 提前堆积；比较下游流深。
3. **拓宽/导流**：修改局部地形/边界；比较到达时间/影响范围。
4. **监测点**：在沟道关键点布设 `h/abs(u)` 监测；用 Q4 时间线选点。
5. **预警联动**：Q4 的 `T_travel` 回填 Q3；检查坝缩短/延后到达时间。

> 只做 2–3 组相对效果，不给“最优工程”；工程参数/成本不在附件内。
