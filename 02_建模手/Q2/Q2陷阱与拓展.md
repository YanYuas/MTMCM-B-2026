## 一、工程级陷阱（T1–T15）

| 编号 | 陷阱 | 现象 | 对策 |
|---|---|---|---|
| T1 | CRS 混用 | CGCS2000/WGS84/UTM45N 混用 | 统一重投影到 UTM45N；记录原 CRS |
| T2 | 像元面积 | 用度²当 km² | 投影后算像元面积；数据窗口 `cell_area_km2=0.000835` |
| T3 | DEM nodata | -32767 参与坡度/汇流 | 掩膜；不填 0 |
| T4 | D8 sink | 未填洼汇流终止 | 用填洼 D8；sink 161 vs 4888 |
| T5 | 沟道阈值 | accum≥1000 是情景 | 报告 500/1000/2000 敏感性 |
| T6 | 土地覆盖 0 | 当类别 | 0=nodata；1–10 不命名 |
| T7 | 冰川 mask | -9999 参与距离 | 掩膜；距离用有效像元 |
| T8 | 栅格对齐 | 不同分辨率直接叠加 | 最近邻/双线性；记录方法 |
| T9 | 多边形栅格化 | 边缘像元归属 | 像元中心规则；2 km 缓冲 |
| T10 | 类别不平衡 | 正例 407k vs 背景 1.67M | 分层/权重；不随机过采样 |
| T11 | AUC 空正例 | 某块无正例 | 跳过该块；报告 |
| T12 | WOE 零背景箱 | log(0) | 加 0.5 平滑；记录 |
| T13 | logistic 完全分离 | 系数爆炸 | 正则化/少因子 |
| T14 | 图中文方框 | mathtext 中文 | 中文不进 `$...$`；检查 PNG |
| T15 | 角度单位 | `tanβ` 用度 | 统一转弧度；记录 |

## 二、边界情形处理

| 情形 | 处理 |
|---|---|
| 沟域完全在 DEM 外 | `in_dem=False`；不参与空间模型；标注 |
| 沟域无冰川像元 | `glacier_fraction=0`；`dist_to_glacier=99999`；单独标记 |
| `m_cr<=0` | 饱和也稳定；`I_rain=0` |
| `m_cr>1` | 饱和也不到临界；`I_rain=0` |
| `φ'<=β` | `tanβ/tanφ'>=1`，`m_cr` 可能 ≤0；按判读处理 |
| `β→90°` | `cosβ→0`；限制 β≤60° 或加小量 |
| `tanφ'→0` | 公式发散；限制 φ'≥15° |
| 某空间块无正例 | 跳过 AUC；报告“无正例块” |
| 某折测试集无背景 | 调整缓冲/块；报告 |
| 土地覆盖 0 占比高 | 0 排除；报告有效像元 |
| DEM 边界/沟道出口 | 流路可能截断；标注 |
| 2026/2025 无降雨 | 走冰崩/GLOF 分支；不强行降雨触发 |
| GLOF 无数据 | `I_glof` 定性/情景；不构造概率 |
| 事件后影像 | 不用做灾前特征；只做验证/背景 |

## 三、边界情形与论文写法

| 情形 | 论文写法 |
|---|---|
| 空间块 AUC 低 | “空间外推有限；全局像素 AUC 受自相关影响偏乐观” |
| 几何因子无提升 | “几何因子未提升空间外推；保留基线，讨论原因” |
| 2026/2025 非降雨 | “两次本地事件均非降雨触发；模型需多分支” |
| GLOF 无编目 | “数据不足，只做定性/情景；不构造概率” |
| DEM 时点未知 | “获取时点未知；做灾前/灾后情景；写局限” |
| 土地覆盖无图例 | “保留编码 1–10；不命名类别” |
| 23/84 沟域 | “登记沟域标签，不是事件；空间外推有限” |

## 四、拓展方向

1. **事件目录**：补年鉴/通报/论文，≥5 个本地事件后再评估频率/覆盖率。
2. **冰湖编目**：Sentinel-2/Planet 解译湖面积、坝高、自由board；建 GLOF 筛选。
3. **DEM 时点/地形变化**：灾前 DEM、ICESat-2、InSAR；做地形变化与时间泄漏检查。
4. **InSAR 形变**：冰川/坡体位移；源区失稳前兆。
5. **贝叶斯网络**：有更多事件后，把三条件/触发模式写成条件概率。
6. **Q4 耦合**：用 Q4 的到达范围/流深修正 Q2 的“影响对象”权重。
7. **监测点优化**：在主流路 49.62 km 上做监测点/检查坝选址（拓展，不进主线）。
