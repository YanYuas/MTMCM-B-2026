# Q2 建模数学化

> 版本：v1.0.0 | 日期：2026-10-24 | 状态：🔄 建模中
> 用途：把 Q2 写成严格数学形式——几何因子、临界阈值、空间易发性、断层树集成、可靠性约束。

## 一、对象与符号

| 符号 | 含义 |
|---|---|
| `g` | 沟域/评估单元，`g=1..84`；其中 23 个落在 DEM 内 |
| `p` | DEM 像元 |
| `β` | 坡度（度/rad） |
| `z` | 高程（m）或土层深度（m），按上下文 |
| `A_g` | 沟域面积（km²） |
| `L_ch` | 沟道长度（km） |
| `S_g` | 空间易发性（相对，0–1） |
| `I_rain` | 降雨触发指示（0/1） |
| `I_ice` | 冰崩/冰川失稳触发指示（0/1） |
| `I_glof` | 冰湖溃决触发指示（0/1，情景/定性） |
| `I_trig` | 综合触发指示：`max(I_rain,I_ice,I_glof)` |
| `H` | 条件触发评分：`H=S_g·I_trig`，不是概率 |
| `m` | 饱和度 `z_w/z` |
| `m_cr` | 临界饱和比 |
| `FS` | 边坡安全系数 |
| `I` | 降雨强度（mm/h） |
| `D` | 降雨历时（h） |
| `a,b` | I-D 阈值参数（文献/区域） |
| `API` | 前期降水指数（mm） |

**评估域**：DEM 实际覆盖 `85.1898–85.6941°E, 28.2455–28.5644°N`；主流路 49.622 km，落差 3992.74 m，比降 8.046%；84 个沟域中 23 个在 DEM 内。

## 二、几何因子（8 个，物理预选）

| ID | 名称 | 定义 | 单位 | 物理含义 |
|---|---|---|---|---|
| G1 | `slope_mean` | 沟域内坡度均值 | ° | 能量条件 |
| G2 | `slope_p90` | 沟域内坡度 90 分位 | ° | 陡坡占比 |
| G3 | `relief` | `z_max - z_min` | m | 势能 |
| G4 | `hypsometric_integral` | `(z_mean - z_min)/(z_max - z_min)` | – | 流域演化/物源 |
| G5 | `drainage_density` | `L_ch / A_g` | km/km² | 汇水效率 |
| G6 | `channel_gradient` | `(z_source - z_outlet)/(10·L_ch)` | % | 传播能量 |
| G7 | `dist_to_glacier` | 沟域像元到最近冰川像元的最小距离 | m | 物源/触发距离 |
| G8 | `glacier_fraction` | 沟域内冰川/冰碛像元占比 | – | 物源 |

**约束**：

- 只用物理可解释的 8 个；曲率/沟道凹度等作 P1，不进主模型。
- 全部在 DEM/沟域尺度计算；不做“30 个因子 + 遗传算法”的自由搜索。
- 标准化用训练折的均值/标准差，不能全数据标准化（防泄漏）。

## 三、临界条件

### 3.1 无限边坡：临界饱和比 `m_cr`

对坡度 `β`、土层厚度 `z`、有效黏聚力 `c'`、有效内摩擦角 `φ'`、饱和重度 `γ_sat`、水重度 `γ_w`、地下水位 `z_w`：

```
FS = [c' + (γ_sat·z - γ_w·z_w)·cos²β·tanφ'] / [γ_sat·z·sinβ·cosβ]
```

令 `FS=1`，记 `m=z_w/z`、`r=γ_w/γ_sat`：

```
m_cr = (1/r)·[1 - tanβ/tanφ' + c'/(γ_sat·z·cos²β·tanφ')]
```

**判读**：

- `0 < m_cr <= 1`：可达临界；降雨/融水使 `m(t) >= m_cr` 时触发可能。
- `m_cr <= 0`：饱和也稳定（`FS>1`），不产生降雨触发。
- `m_cr > 1`：即使饱和也不到临界（`FS>1`），不产生降雨触发。
- 参数 `c'`、`φ'`、`γ_sat`、`z` 未标定 → 用区间/情景，不给单点“真值”。

### 3.2 降雨 I-D 阈值

```
I_c(D) = a·D^(-b)          [mm/h]
I_rain = 1 if I_obs(D) >= I_c(D) else 0
```

- `a,b` 来自文献/邻区；**不能用 2 个本地事件校准**（2026/2025 都非降雨触发）。
- `D` 取 1/3/6/12/24/48/72 h；`I_obs` 用 CHIRPS/ERA5/NASA/站点多源；标证据级。
- 若 `m(t) >= m_cr` 可达，则 `I_rain=1`；两种判据取 OR。

### 3.3 前期降水/土壤水

```
API72(t) = Σ_{i=0}^{71} 0.9^i·P(t-i)
I_rain = 1 if API72(t) >= API_c 或 m(t) >= m_cr
```

`API_c` 用文献/情景；`m(t)` 由 Q1 的 VWC/土壤水模型或简化线性水库给；没有连续土壤水观测时，`m(t)` 用情景。

### 3.4 冰崩/冰川失稳筛选

对源区冰川像元 `p`：

```
I_ice = 1 if z(p)>=z0 AND slope(p)>=β0 AND H_ice(p)>=H0 AND v(p)>=v0
```

默认筛选（**情景/文献启发，未标定**）：

| 参数 | 默认 | 依据 |
|---|---:|---|
| `z0` | 5000 m | 2026 源区约 5200 m；高山区冰崩源区 |
| `β0` | 25° | 冰川/岩壁失稳的陡坡筛选 |
| `H0` | 20 m | TPDC-04 冰厚均值 49.59 m；20 m 为下限筛选 |
| `v0` | 5 m/yr | TPDC-04 速度均值 7.84 m/yr；5 m/yr 为活动冰川下限 |

> 这是“筛选”，不是冰力学失稳判据；论文必须写“情景筛选 + 参数区间”。不能用它算冰崩概率。

### 3.5 冰湖溃决（GLOF）

数据缺口：没有冰湖编目/坝高/湖面积/水位序列。只能：

- 用事件目录（2025-07-08 同区域 GLOF、2002-05-23 嘉龙错区域 GLOF）做**定性/案例**；
- `I_glof` 作为**情景标志**：若评估单元位于已知冰湖下游/沟道，标 1；否则 0；
- 不构造“GLOF 概率/阈值”；论文写“数据不足，只能情景”。

## 四、空间易发性 `S_g`

### 4.1 标签

- 正例：84 个历史沟域中 23 个落在 DEM 内的像元；**是“登记沟域”，不是 23 次事件**。
- 负例：DEM 内、沟域外的背景像元；排除沟域边界 2 km 缓冲，避免“沟域边缘”泄漏。
- 类别不平衡：正例 407,821 像元，背景 1,676,947 像元（数据窗口）；训练时按空间块分层，不做随机过采样。

### 4.2 基线（WOE，必须复现）

数据窗口的 WOE 基线：

- 协变量：`slope_deg`、`elevation_m`、`log1p_accum`、`landcover`；
- 全局像素 AUC **0.7472**；2×2 空间块 AUC **0.5279 / 0.6496**；
- 沟域中位百分位 0.815；分箱在全数据上确定（轻微泄漏）。

**要求**：编程手先复现这组数字（容差 ±0.005），再扩展；不能直接换模型跳过基线。

### 4.3 扩展模型

在基线上加几何因子 G1–G8（或其中 3–5 个非冗余因子）+ 冰川因子：

```
logit(S_g) = α + Σ_k β_k·X_k(g)
```

- `X_k` 标准化（训练折均值/标准差）；
- 模型：逻辑回归（可解释基线）+ 可选梯度提升（仅作对照）；
- 变量选择：物理预选 + 空间块 CV；**不用全数据 p 值/逐步回归**；
- 输出 `S_g`：预测分数的**百分位**（0–1），标“相对易发性”，不是概率。

### 4.4 空间验证（主指标）

1. **Leave-one-gully-out**：23 折；每折留出一个沟域，训练用其余 22 个 + 背景；测试留出沟域像元 + 2 km 缓冲外背景；算 AUC/PR-AUC。
2. **2×2 / 3×3 空间块**：按 DEM 范围分块；训练用其余块，测试留出块；只报告有正例的块。
3. **缓冲**：留出沟域外 2 km 内的背景不参与训练/测试，防空间泄漏。
4. **报告**：AUC/PR-AUC 的均值±标准差、每折/每块表；**不以全局像素 AUC 为主**。

### 4.5 尺度敏感性

| 尺度 | 取值 | 目的 |
|---|---|---|
| DEM | 30/60/90 m | 沟道/坡度对分辨率敏感 |
| 缓冲 | 1/2/3 km | 空间泄漏与样本量 |
| 空间块 | 2×2/3×3/4×4 | 空间外推 |
| 降水 | 0.05°/0.25° | 触发变量尺度 |
| 土地覆盖 | 30 m 原值/多数聚合 | 类别/边界 |

报告指标随尺度的变化范围；不只报“最优尺度”。

## 五、断层树集成

### 5.1 三条件 AND

```
Terrain_ok(g) = [slope_mean(g) >= β_min] AND [relief(g) >= R_min] AND [channel_gradient(g) >= G_min]
Material_ok(g) = [landcover(g) in {物源候选}] OR [glacier_fraction(g) >= F_min]
Water_ok(g,t) = I_rain(t) OR I_ice OR I_glof
Trigger_possible(g,t) = Terrain_ok AND Material_ok AND Water_ok
```

- `β_min`、`R_min`、`G_min`、`F_min` 用文献/情景；不给单点“真值”。
- `landcover` 1–10 无图例 → 不命名类别；`Material_ok` 只用“编码集合/冰川占比”，并在论文写“编码未命名”。

### 5.2 条件触发评分

```
I_trig(g,t) = max(I_rain(t), I_ice(g), I_glof(g))
H(g,t) = S_g · I_trig(g,t)
```

- `H` 是“条件触发评分”，范围 0–1；**不是概率**。
- 分级：`H=0` 无触发；`0<H<=0.33` 低；`0.33<H<=0.66` 中；`>0.66` 高。
- 论文写“条件触发等级/情景”，不写“发生概率”。

### 5.3 事件案例检查

| 事件 | `I_rain` | `I_ice` | `I_glof` | 期望 |
|---|---:|---:|---:|---|
| 2026-08-26 冰崩链 | 0（站点/再分析/CHIRPS 均低） | 1（源区 5200 m/陡坡/冰厚） | 0/待核 | 通过冰崩分支触发 |
| 2025-07-08 GLOF | 0 | 0/待核 | 1（冰湖溃决） | 通过 GLOF 分支触发 |
| 2002-05-23 嘉龙错 | — | — | 1（区域类比） | 不计入本地频率 |
| 2015-04-25 地震 | — | — | — | 物源背景，不是触发 |

> 2 个本地事件只能做“案例一致性”，不能算准确率/覆盖率。

## 六、约束条件

| 编号 | 约束 | 含义 |

| C1 | 不用事件后数据 | 事件后影像/DEM 不能做灾前特征 |
