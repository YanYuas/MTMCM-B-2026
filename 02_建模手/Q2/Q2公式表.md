## 二、几何因子（G1–G8）

### G1 平均坡度

```
slope_mean(g) = mean(β(p), p∈g)                  [°]
```

### G2 坡度 90 分位

```
slope_p90(g) = quantile_0.9(β(p), p∈g)           [°]
```

### G3 起伏度

```
relief(g) = z_max(g) - z_min(g)                  [m]
```

### G4 面积-高程积分

```
HI(g) = (z_mean(g) - z_min(g)) / (z_max(g) - z_min(g))   [–]
```

`HI∈[0,1]`；越大表示高程分布越偏上（幼年期/物源潜力）。

### G5 汇流密度

```
Dd(g) = L_ch(g) / A_g                             [km/km²]
```

`L_ch` 用填洼 D8 沟道掩膜（accum≥1000 cells）或主流路；`A_g` 用像元面积求和。

### G6 主沟/沟道比降

```
S_ch(g) = (z_source - z_outlet) / (10·L_ch)       [%]
```

`z` 用 m，`L_ch` 用 km；`drop_m/(L_km·10)=%`。主沟 3992.74 m / 49.622 km → 8.046%。

### G7 到冰川距离

```
dist_to_glacier(g) = min_{p∈g, q∈glacier} distance(p,q)   [m]
```

用 TPDC-04 `glacier_mask.tif`；投影到 UTM45N 后算欧氏距离；无冰川时记大值（如 99999）并在模型中单独标记。

### G8 冰川/冰碛占比

```
glacier_fraction(g) = N_glacier(p∈g) / N_all(p∈g)         [–]
```

`N_glacier` 用 TPDC-04 mask；土地覆盖编码不能替代冰川 mask（无图例）。

## 三、临界阈值（T1–T7）

### T1 无限边坡安全系数

```
FS = [c' + (γ_sat·z - γ_w·z_w)·cos²β·tanφ'] / [γ_sat·z·sinβ·cosβ]
```

`c'` kPa = kN/m²；`γ` kN/m³；`z` m；`β` 用弧度。

### T2 临界饱和比

```
m = z_w/z
r = γ_w/γ_sat
m_cr = (1/r)·[1 - tanβ/tanφ' + c'/(γ_sat·z·cos²β·tanφ')]
```

### T3 `m_cr` 判读

```
if m_cr <= 0:  I_rain = 0      # 饱和也稳定
elif m_cr > 1: I_rain = 0      # 饱和也不到临界
else:          I_rain = 1 if m(t) >= m_cr else 0
```

### T4 降雨 I-D 阈值

```
I_c(D) = a·D^(-b)              [mm/h]
I_rain = 1 if I_obs(D) >= I_c(D) else 0
```

`a,b` 用文献/邻区；`D` 取 1/3/6/12/24/48/72 h；**不能用 2 个本地事件校准**。

### T5 前期降水指数

```
API72(t) = Σ_{i=0}^{71} 0.9^i·P(t-i)             [mm]
I_rain = 1 if API72(t) >= API_c 或 m(t) >= m_cr else 0
```

`API_c` 用文献/情景；`m(t)` 由 Q1 土壤水或简化线性水库给。

### T6 冰崩/冰川失稳筛选

```
I_ice = 1 if z >= z0 AND slope >= β0 AND H_ice >= H0 AND v >= v0 else 0
```

默认（情景/文献启发）：

```
z0=5000 m, β0=25°, H0=20 m, v0=5 m/yr
```

> 这是筛选，不是冰力学失稳判据；参数给区间，论文标 C。

### T7 GLOF 触发（定性/情景）

```
I_glof = 1 if 评估单元位于已知冰湖下游/沟道 else 0
```

数据不足：没有冰湖编目/坝高/湖面积/水位序列；只能用 2025/2002 事件做案例，不构造概率。

## 四、空间易发性与集成（S1–S4）

### S1 WOE 基线

```
WOE_i = ln( (P_i/P_total) / (B_i/B_total) )
S_woe = Σ_i WOE_i
```

`P_i` 正例像元数，`B_i` 背景像元数；分箱只在训练折确定（防泄漏）。

### S2 逻辑回归扩展

```
logit(S_g) = α + Σ_k β_k·X_k(g)
S_g = 1/(1+exp(-logit))          # 预测分数
S_g^rel = percentile_rank(S_g)    # 相对易发性 0–1
```

`X_k` 标准化（训练折均值/标准差）；模型选择用空间块 CV，不看全局像素 AUC。

### S3 空间验证指标

```
AUC = P(score(positive) > score(negative))
PR-AUC = 积分 Precision·dRecall
```

留一沟域（23 折）+ 2 km 缓冲；2×2/3×3 空间块；报告均值±标准差、每折表。

### S4 条件触发评分

```
I_trig(g,t) = max(I_rain(t), I_ice(g), I_glof(g))
H(g,t) = S_g^rel · I_trig(g,t)
```

`H∈[0,1]`；分级 0/低/中/高；**不是概率**。

## 五、已知答案验证（给编程手）

| 编号 | 输入 | 期望 |

| V7 | `z_min=1000, z_max=3000, z_mean=1800` | `HI=0.4` |
| V8 | `L_ch=10km, A_g=20km²` | `Dd=0.5 km/km²` |
| V9 | 冰川像元 25，沟域像元 100 | `glacier_fraction=0.25` |
