## 一、工程级陷阱（T1–T15）

| 编号 | 陷阱 | 现象 | 对策 |
|---|---|---|---|
| T1 | 时间格式不统一 | MET `2021-1-1 0:00`，FLUX `2021/1/1 0:00` | 两套解析格式；解析后统一 `datetime64[ns]`；保留原始字符串 |
| T2 | 9999.9 混入 | 被当真实值参与均值/排序 | 解析时 `9999.9 -> NaN`；统计缺失率 |
| T3 | QC=8 未剔除 | 缺测码进入特征 | `QC=8 -> NaN`；`QC=1/2 -> suspect`；主分析剔除 suspect |
| T4 | 负辐射值 | `Rsd`/`Rld` 出现负值 | 标 suspect；`Rn`/反照率主分析置缺失；敏感性截断 0 |
| T5 | 2026 年末空白行 | 时间网格到 12-31 | 以有效观测截止；不用未来行；`max(t) <= 2026-08-27` |
| T6 | FLUX 缺测 32% | H/LE/u*/TKE 大量缺失 | 有效率门槛；敏感性；报告缺失率 |
| T7 | 风向跨 0° | 350°→10° 差值 340° | 最小夹角；`1-cos`；或矢量 |
| T8 | 气压单位 | hPa vs kPa | 基础公式统一 hPa；B3/B4 写明 |
| T9 | 辐射单位 | W/m² vs MJ/m²/day | 检查表头；统一 W/m² |
| T10 | 土壤深度单位 | cm vs m | 统一 m；B11 写明层厚 |
| T11 | 24/72 h 滚动缺失 | 中间缺 1 h，整段应缺失 | 任缺→缺失；不补零；`min_periods` 设满 |
| T12 | 重复时间戳 | 合并 CSV 时重复 | `drop_duplicates(timestamp)`；报告重复数 |
| T13 | 闰年/时区 | 2024 闰年、UTC+8 | 用时间戳对齐；不按“天数×24”硬编码 |
| T14 | 置换实现错误 | 逐点打乱/跨年混排 | 循环块；每年内取窗口；固定随机种子 |
| T15 | BH 实现错误 | 直接 `p*m` 不单调 | 用 `statsmodels.stats.multitest.multipletests(method='fdr_bh')` 或手写单调化 |

## 二、边界情形处理

| 情形 | 处理 |
|---|---|
| `Precip` 全 0（事件窗口/基线） | `A=0`；`z` 用分位映射；不报“负异常” |
| `MAD=0` | `IQR/1.349`；仍 0 → 分位映射；截断 |
| `ΔU<0.1` | `Ri_b` 缺失；不除零 |
| `Rsd<=50` | 反照率缺失；不除零 |
| `abs(LE)<=10` | 波文比缺失；不除零 |
| `Rsd<0` 或 `Rld<0` | 标 suspect；主分析缺失；敏感性截断 0 |
| 事件窗口有效率 <70% | 该特征不参与主排名；列入“不可用”表 |
| 基线有效率 <70% | 该特征不参与；检查缺测年份 |
| 2026 事件后数据 | 只用于 `E_all` 描述；不进入基线/前兆排序 |
| 事件窗口跨日 | 用时间戳切片，不按“第几天”硬编码 |
| 同一特征多个单位列 | 用列名映射表；只取一个；记录映射 |
| 输出表有 NaN | 排名表不允许 NaN；不可用特征单独表 |
| 图中文方框 | 中文不进 mathtext；图后检查 PNG |
| 结果与数据窗口审计不一致 | 先查时间解析/缺失规则；写 `理论问题反馈.md` |

## 三、边界情形与论文写法

| 情形 | 论文写法 |
|---|---|
| 站点 72 h 降水 0 | “站点尺度无强降水；源区水源需再分析/卫星补充” |
| Top5 不稳定 | “排序对基线/窗口敏感；Top5 仅作候选” |
| 某组无特征入选 | “该组在事件窗口无稳定异常；不代表该过程不重要” |
| FLUX 缺测高 | “湍流特征受缺测限制；结论以有效样本为准” |
| 2026 数据短 | “事件后仅 1 天；不做恢复/长期趋势” |
| 单事件 | “描述性关联，非因果；需要多次事件验证” |

## 四、拓展方向

1. **多次事件目录**：补 5–10 次有日期的事件，做事件级排序稳定性/覆盖率。
2. **源区观测**：尼泊尔一侧冰崩、降水、位移；解决 65 km 代表性。
3. **卫星/再分析**：GPM/CHIRPS/Sentinel-1/2；做空间对照，但注意事件后影像不能做灾前特征。
4. **因果图**：把“辐射→土壤水热→入渗→触发”写成 DAG；用多事件/干预验证。
5. **极端值理论**：降水/温度 EVT，给重现期；单事件只能做站点极值。
6. **特征选择稳定性**：stability selection/LASSO 对照；不替代物理排序。
7. **可解释机器学习**：作为辅助异常检测（Isolation Forest），与主排序对照；不声称因果。
