# Q1 几何优化（观测几何）

> 版本：v1.0.0 | 日期：2026-10-24 | 状态：🔄 可选 P1
> 用途：回答“Q1 能否设计几何优化”——能，但只能是**观测几何/特征层几何**，不是 Q4 的网格几何，也不是传感器选址。
> 配套：[`Q1建模数学化.md`](Q1建模数学化.md)、[`Q1公式表.md`](Q1公式表.md)、[`Q1字段映射.md`](Q1字段映射.md)
> 定位：**可选增强模块**，不替代 Q1 的 33 特征主排序；最多采纳 2 个几何特征。

---

## 0. 一句话

**Q1 的“几何”不是空间布局，而是“观测几何”：多层塔的风/温/湿层对、土壤剖面深度、湍流通量 footprint 扇区、站点—源区方位。几何优化 = 在这些离散候选几何中，选一个物理可解释、数据完整、排名稳定的层对/扇区，而不是用遗传算法在单事件上搜一个“最高分”。**

---

## 1. Q1 有哪些“几何”可优化

| 几何层 | 数据 | 当前做法 | 可优化的对象 |
|---|---|---|---|
| 垂直风/温/湿 | MET 1/2/4/10/20 m | 固定 2–10、2–20 | 层对：2–10、2–20、4–20、10–20、1–20 等 |
| 土壤温度 | SOIL 0.1/0.2/0.4/0.8/1.6 m | 固定 0.1–0.4 | 深度对：0.1–0.2、0.1–0.4、0.1–0.8、0.1–1.6、0.4–1.6 |
| 土壤水分 | SOIL 5 层 VWC | 固定 0.4 m + 0–40 cm 储水 | 储水层：0–0.1、0–0.2、0–0.4、0–0.8、0–1.6 m |
| 湍流通量 footprint | FLUX `FETCH_MAX/90/55/40` + `WD` | 未用 | 扇区宽度（30/45/60/90°）、fetch 阈值（50/100/200 m） |
| 站点—源区方位 | 站点坐标 + 口岸/源区坐标 | 未用 | 源区方位扇区、上风向分量 `cos(WD-bearing)` |

> 不能优化的：站点位置（只有一个站）、传感器高度（已固定）、Q4 的网格/释放区。那些属于 Q2/Q4，不要混进 Q1。

## 2. 候选几何（离散、可枚举）

### 2.1 垂直风切变

候选层对：

```
(1,20), (2,4), (2,10), (2,20), (4,10), (4,20), (10,20)
```

约束：`Δz >= 2 m`；两层 `WS`/`QC` 均有效；`S_ws = (WS_hi-WS_lo)/Δz`。

### 2.2 虚温梯度 / bulk Richardson

候选层对：

```
(2,10), (2,20), (4,20), (10,20)
```

约束：两层 `Ta`、`RH`、`Pressure` 有效；`θv` 用 B4/B5；`Ri_b` 用 B8；`abs(ΔU)>=0.1`。

### 2.3 土壤温度梯度

候选深度对：

```
(0.1,0.2), (0.1,0.4), (0.1,0.8), (0.1,1.6), (0.2,0.8), (0.4,1.6)
```

约束：`Δz >= 0.1 m`；两层 `soilT`/`QC` 有效；`GradT=(T_hi-T_lo)/Δz`（深度向下为正时注意符号）。

### 2.4 土壤储水层

候选层：

```
0–0.1, 0–0.2, 0–0.4, 0–0.8, 0–1.6 m
```

用 VWC 测量深度近似层厚：0–0.1=100 mm，0.1–0.2=100 mm，0.2–0.4=200 mm，0.4–0.8=400 mm，0.8–1.6=800 mm；`W=Σ VWC_i·Δz_i·1000` mm。缺层→缺失，不插值。

### 2.5 Footprint 扇区

- 扇区：8 方位（N/NE/E/SE/S/SW/W/NW）或 16 方位；扇区宽度 45° 或 22.5°；
- fetch 阈值：`FETCH_90 >= 50/100/200 m`；
- 对每个扇区/阈值，计算 `WS/Ta/RH/Precip` 的扇区均值/最大值，作为候选特征；
- 只用有效小时；扇区样本 <30 h 不参与。

### 2.6 站点—源区方位

- 站点：28.86°N, 85.29°E, 4140 m；
- 口岸/源区坐标需用官方/地图核（当前未定；先作为参数 `bearing_source`，做 ±15° 敏感性）；
- 特征：
  - `upwind = cos(WD - bearing_source)`（+1=风从源区来，-1=风朝向源区）；
  - `source_sector = I(abs(最小夹角(WD-bearing_source)) <= 45°)`；
  - `fetch_source = FETCH_90 * source_sector`。
- 坐标未核前，只做“方位敏感性”，不写具体角度结论。

## 3. 优化协议（约束优先，不是单事件最大化）

### 3.1 约束

| 编号 | 约束 | 含义 |
|---|---|---|
| G1 | 物理可解释 | 层对/深度/扇区必须对应已知过程；不能是任意组合 |
| G2 | 完整率 ≥70% | 事件窗口与基线都满足；否则不参与 |
| G3 | `q_j <= 0.10` | 与主排序相同的置换 + BH |
| G4 | 稳定性 ≥70% | 年份 bootstrap 中 Top5 频率 ≥70% |
| G5 | 非冗余 | 与现有 33 特征 `abs(ρ)<0.85`；否则只作敏感性 |
| G6 | 简约 | 最多采纳 2 个几何特征；不替换主特征 |

### 3.2 选择顺序（字典序）

```
1. 过 G1/G2
2. 过 G3（置换 p + BH q）
3. 过 G4（bootstrap Top5 频率）
4. 过 G5（非冗余）
5. 在剩余候选中按 A_std 降序；若 A_std 接近（差 <0.2），选物理更直接、缺失更少者
6. 最多采纳 2 个；其余放“几何敏感性表”
```

**为什么不是 `max A_std`**：只有一个事件，直接最大化 `A_std` 会选到“对这一次事件最敏感、但对其他年份不稳定”的层对；G3/G4/G5 是防过拟合的约束。

### 3.3 与主排序的关系

- 主排序仍是 33 特征（预注册）；
- 几何优化是**敏感性/增强**：先报告“固定几何”的 Top5，再报告“几何候选”的排名变化；
- 如果几何特征进入 Top5，必须在论文中说明“这是几何敏感性分析的结果，不是事后替换主特征”；
- 如果几何特征不稳定，只写“层对/深度选择对 Top5 有影响”，不强行采纳。

## 4. 公式

### 4.1 层对风切变

```
S_ws(i,j) = (WS_j - WS_i)/(z_j - z_i)      [s^-1]
```

### 4.2 层对虚温梯度 / Ri_b

```
Δθv(i,j) = θv_j - θv_i                     [K]
Ri_b(i,j) = g·Δθv·(z_j-z_i)/(θv_mean·(ΔU)^2)
```

### 4.3 深度对土壤温度梯度

```
GradT(i,j) = (soilT_j - soilT_i)/(z_j - z_i)   [°C/m]
```

深度向下为正；`z_j>z_i`。

### 4.4 储水层

```
W(L) = Σ_{i in L} VWC_i·Δz_i·1000          [mm]
```

### 4.5 扇区特征

```
sector_t = argmax_k I(WD_t in sector_k)
X_sector(k) = mean(X_t | sector_t=k, FETCH_90_t >= F)
```

### 4.6 源区方位

```
Δ = 最小夹角(WD - bearing_source)
upwind = cos(Δ)
source_sector = I(abs(Δ) <= 45°)
```

## 6. 预期结论形态（不是最终数字）

- 2–10 m 与 2–20 m 风切变可能高度相关；二选一或都保留（同簇最多 2 个）；
- 0.1–0.4 m 土壤温度梯度可能比 0.1–1.6 m 更敏感，但后者更稳；
- 0–0.4 m 储水可能比单层 0.4 m VWC 更稳；
- footprint 扇区可能筛掉“非代表性”小时，使排序更稳，但会减少样本；
- 源区方位特征可能提供“上风向/下风向”解释，但坐标未核前只能做敏感性。

> 以上只是“可能”，必须由实际 `q1_geometry_candidates.csv` 决定；不能预写进论文。

## 7. 红线

1. **不把 Q1 几何优化做成“空间传感器选址”**：只有一个站，不能优化站点位置；选址属于 Q4/防灾拓展。
2. **不在单事件上自由搜索层对/扇区**：候选必须离散、物理可解释、过 G1–G6。
3. **不事后替换主特征**：主排序 33 特征先报告；几何特征只作敏感性/增强，最多 2 个。
4. **不把 `A_std` 最大当“最优几何”**：必须看稳定性/完整性/非冗余。
5. **不把 footprint 扇区结果当“源区观测”**：站点仍距口岸 65 km。
6. **不把几何优化写成一个新问题**：它是 Q1 的方法学小节，不是 Q5。

## 8. 实施步骤（给编程手）

1. 读 [`Q1字段映射.md`](Q1字段映射.md)，确认层对/深度/扇区的原始列名与 QC；
2. 生成候选几何表（G01–G30）；
3. 对每个候选，按主排序相同的 `z/A/permutation/BH/bootstrap` 计算；
4. 按 G1–G6 筛选，最多采纳 2 个；
5. 输出候选表 + 敏感性表 + 图；
6. 在 `验证题结果.md` 记录：采纳了哪些、为什么、对 Top5 的影响；
7. 建模手独立复算后再进论文。

---

## 9. 结论

**Q1 可以设计几何优化，但应定义为“观测几何优化”，并作为可选 P1 模块**：

- 能做：层对/深度/扇区/源区方位的离散选择 + 稳定性约束；
- 不能做：站点选址、Q4 网格、自由超参搜索；
- 价值：证明 Top5 不是“随便选层对”的产物，提升 Q1 方法学严谨性；
- 风险：单事件过拟合；用 G3–G6 约束，最多采纳 2 个。

> 如果时间紧，Q1 主排序优先；几何优化放在 Q1 结果出来后做“敏感性小节”，不要阻塞编程手。
