## 二、基础公式（B1–B12）

### B1 饱和水汽压

```
e_s(T) = 0.6108 · exp(17.27·T / (T + 237.3))     [kPa]
```

`T` 为 °C。

### B2 水汽压

```
e = e_s(T) · RH/100                              [kPa]
```

### B3 比湿

```
q = ε·e / (P - 0.378·e)                          [kg/kg]
```

`e` 用 kPa，`P` 用 hPa 时需 `P/10` 转 kPa；建议统一：`e_kPa`、`P_kPa = P_hPa/10`。

### B4 位温

```
θ = (T + 273.15) · (1000/P_hPa)^0.286            [K]
```

`P_hPa` 为 hPa；不要混用 kPa。

### B5 虚位温

```
θv = θ · (1 + 0.61·q)                            [K]
```

### B6 风矢量分量

```
u = WS · sin(WD·π/180)
v = WS · cos(WD·π/180)                           [m/s]
```

气象风向为“风的来向”；`sin/cos` 只用于矢量差，符号不影响 `ΔU` 的模。

### B7 风矢量差

```
ΔU = sqrt((u_hi-u_lo)^2 + (v_hi-v_lo)^2)         [m/s]
```

### B8 bulk Richardson 数

```
Ri_b = g·(θv_hi-θv_lo)·Δz / (θv_mean·(ΔU)^2)     [–]
Δz = z_hi - z_lo                                 [m]
θv_mean = (θv_hi + θv_lo)/2                      [K]
```

`abs(ΔU)<0.1` 记缺失；`Ri_b<0` 不稳定，`>0` 稳定。

### B9 净辐射

```
Rn = Rsd - Rsu + Rld - Rlu                       [W/m²]
```

向下为正；任一分量缺失则 `Rn` 缺失。

### B10 饱和水汽压差

```
VPD = e_s(Ta_2m) · (1 - RH_2m/100)                [kPa]
```

`VPD>=0`；浮点误差截断到 0。

### B11 土壤储水（0–40 cm）

```
W = 100·VWC_0.1 + 100·VWC_0.2 + 200·VWC_0.4      [mm]
```

层厚：0–0.1 m=100 mm，0.1–0.2 m=100 mm，0.2–0.4 m=200 mm。

### B12 前期降水指数

```
API72(t) = Σ_{i=0}^{71} 0.9^i · P1(t-i)          [mm]
```

`P1` 为小时降水；72 h 内任一缺失 → 缺失。

## 四、异常、聚合、显著性（S1–S7）

### S1 稳健异常

```
med_j = median(X_j(t), t∈B)
mad_j = median(abs(X_j(t)-med_j), t∈B)
scale_j = 1.4826·mad_j
z_j(t) = (X_j(t)-med_j)/scale_j
```

若 `scale_j=0`：用 `IQR_j/1.349`；若仍 0，用经验分位映射：

```
u_j(t) = (rank_B(X_j(t)) - 0.5)/n_B
z_j(t) = Φ^{-1}(u_j(t))，截断 [-3.5,3.5]
```

`Precip/API` 先 `log1p`；`Φ^{-1}` 为标准正态分位函数。

### S2 连续特征窗口聚合

```
A_j = mean_{t∈E} abs(z_j(t))
D_j = mean_{t∈E} z_j(t)
```

### S3 二值特征窗口聚合

```
A_j = rate_E,j - rate_B,j
rate_E,j = mean_{t∈E} I_j(t)
rate_B,j = mean_{t∈B} I_j(t)
D_j = sign(A_j)
```

### S4 置换零分布

```
mean_null_j = mean_b A_j^(b)
sd_null_j   = sd_b A_j^(b)
A_j^std     = (A_j - mean_null_j)/sd_null_j
p_j         = (1 + #{b: A_j^(b) >= A_j})/(B+1)
```

`B=1000`；在 `S_y` 内取与 `E` 等长的窗口，保留日变化/自相关。`sd_null_j=0` 时 `A_j^std=0`、`p_j=1`。

### S5 BH FDR

```
把 p_j 升序排列 p_(1) <= ... <= p_(m)
q_(i) = min_{k>=i} (m/k · p_(k))
q_j = q_(i) for p_j=p_(i)
```

`m=33`；`q_j<=0.10` 通过。

### S6 排名与稳定性

```
R_j = rank(-A_j^std)        # 1=最高
```

年份 bootstrap：`B=500`，有放回抽 6 年，重算 `med/mad/A_j`，用固定 `mean_null/sd_null` 标准化，重排名；输出中位排名、2.5%/97.5% 区间、Top5 频率。另做 leave-one-year-out（6 次）。

### S7 非冗余聚类

```
ρ_jk = Spearman(X_j(B), X_k(B))
若 abs(ρ_jk) >= 0.85，则 j,k 同簇
```

同一簇最多保留 2 个；优先 `A_j^std` 大、物理最直接者。

---

## 五、Top5 选择规则

1. 通过 `q_j<=0.10`、`valid_E>=70%`、`valid_B>=70%`、物理机制明确。
2. 非冗余：同簇最多 2 个。
3. 按 `A_j^std` 降序取前 5。
4. 若不足 5 个，按 `A_j^std` 补足，标“探索性”。
5. 输出字段：`feature_id, name, group, A_j, A_j^std, p_j, q_j, D_j, median_rank, rank_lo, rank_hi, top5_freq, direction, evidence_level`。
