## 一句话定位

**Q1 = 单事件条件下的高寒山区边界层/水热异常特征排序 + 可复现的不确定性评估。**

数据为 2021–2026 年逐小时 MET/RADM/SOIL/FLUX；核心难点是**只有一次已知事件、缺测约 11%–32%、单点距口岸约 65 km**；解法 = 物理特征体系 + 同季节/同时刻基线 + 稳健异常 + 循环块置换检验 + 年份 bootstrap 排名稳定性 + 非冗余筛选；验证 = 已知答案、零模型校准、合成异常注入、缺测/窗口敏感性；防坑 = 不把相关当因果、不把单点当区域、不把 Top5 当“原因排序”。

## 题设逐词点透（摘要）

> 题目原文：“基于气象梯度数据（MET）、辐射数据（RADM）、土壤数据（SOIL）以及湍流数据（FLUX）等，进行吉隆县及其周边高寒山区大气边界层结构、天气过程及极端气象事件与吉隆泥石流关联性的特征分析，并给出关联性排序最高的 5 个特征因素。”

| 词 | 字面 | 点透（对 Q1 的影响） |
|---|---|---|
| 气象梯度 | 多层风/温/湿 | 1/2/4/10/20 m 的风、温、湿梯度 → 风切变、虚温梯度、bulk Richardson |
| 辐射 | 四分量 | `Rn = Rsd - Rsu + Rld - Rlu`；反照率、云量代理、地表加热 |
| 土壤 | 多层水热 | 0.1–1.6 m 土壤温度/含水率、地表热通量 → 前期含水量、融水入渗 |
| 湍流 | H/LE/u*/TKE | 感热/潜热分配、动量输送、稳定度 |
| 边界层结构 | 稳定度/混合层 | 用梯度 + 湍流联合刻画；不能只看单层风速 |
| 天气过程 | 天气尺度 | 气压倾向、降水、辐射过程；不能只看小时异常 |
| 极端气象事件 | 极端阈值 | 用基线 95/99 分位定义，先注册阈值再统计 |
| 关联性 | 不是因果 | 单事件只能做“事件窗口异常 + 稳定性”；不能做因果推断 |
| Top5 | 排序 | 排名必须带不确定性；不能只给名单 |

**点透结论**：Q1 不是“训练一个泥石流分类器”，而是“在只有一次事件的条件下，构造物理上可解释的特征，并给出可复现、可反驳的关联性排序”。

## 不确定量清单（元断言：逐一取最坏）

| 不确定量 | 范围/分布 | 最坏取值 | 对结论的影响 | 处理 |
|---|---|---|---|---|
| 事件时刻对齐 | 10:30 vs 小时网格 | 取 10:00 或 11:00 | 事件窗口偏移 1 h | 主窗口用 10:00 为最后完整小时；敏感性 ±1 h |
| 基线窗口宽度 | ±7/±15/±30 天 | ±7 天样本少、±30 天季节漂移 | Top5 排名变化 | 主 ±15 天；敏感性 ±7/±30 |
| 缺测 | MET/SOIL ~11%，FLUX ~32% | 事件窗口关键变量缺失 | 特征不可算/偏差 | 有效率 ≥70%；不补零；敏感性 |
| QC 可疑 | QC=1/2 | `Rsd` 负值、`Rld` 负值 | 辐射特征偏差 | 主分析剔除可疑；敏感性保留 |
| 单点代表性 | 站点距口岸 65 km | 源区降水/边界层不同 | Top5 不代表源区 | 明确写“站点尺度”；再分析只作对照 |
| 特征冗余 | 风/温/湿/辐射高度相关 | Top5 被同一过程占满 | 解释重复 | abs(ρ)≥0.85 聚类，保留物理最直接者 |
| 多重比较 | 33 个特征 | 假阳性 Top5 | 排序不可信 | 循环块置换 + BH FDR |
| 非平稳 | 5 年趋势/年际 | 趋势被当成异常 | 排序偏差 | 同季节基线；敏感性去趋势 |
| 2026 数据末尾 | 有效观测止于 2026-08-27 | 事件后仅 1 天 | 不能做长期恢复分析 | 只用事件前 + 事件后 6 h |
| 极端阈值 | 95/99 分位由基线定 | 阈值选择改变结果 | 极端特征入选/落选 | 先注册阈值；敏感性 90/95/99 |

## 数学结构（“无关联”零模型，不是优化下界）

Q1 没有优化目标，但有“无关联”基线：

1. **平凡零模型**：事件窗口与同季节任意窗口无差别 → `A_j` 的置换分布。
2. **季节零模型**：只匹配季节、不匹配时刻 → 日变化会混入（应避免）。
3. **工程零模型**：同季节 + 同时刻 + 循环块置换 → 本文采用；保留日变化和自相关。

> 结论：Q1 的“显著性”来自**置换零分布**，不是 t 检验；因为小时数据自相关、非正态、单事件。

## 方法路线图

```
原始 24 CSV（MET/RADM/SOIL/FLUX）
  ↓ 解析、QC、时间对齐（UTC+8，保留原始 timestamp）
小时特征矩阵（33 个候选特征，分 6 组）
  ↓ 事件窗口 E_pre、同季节/同时刻基线 B、排除 E72
稳健异常 z_j(t)（中位数/MAD；MAD=0 用经验分位映射）
  ↓ 窗口聚合 A_j（连续：mean |z|；二值：率差）
循环块置换（block=24 h，1000 次）→ 零分布 → p_j、A_j^std
  ↓ BH FDR → q_j
年份 bootstrap / leave-one-year-out → 中位排名、95% 排名区间、Top5 频率
  ↓ 非冗余聚类（|ρ|≥0.85）→ 物理可解释性复核
Top5（附 A、q、方向、排名区间、稳定性、证据等级 [A]）
```

## 关键结论（预期，不是最终数字）

1. **站点 72 h 降水为 0.00 mm**（72/72 有效），而 Open-Meteo 0.70 mm、NASA POWER 8.46 mm。Q1 主排序只用站点；再分析只作对照。**`Precip_72h` 很可能不进入 Top5**，这不是 bug，而是“站点尺度没有强降水”的证据。
2. **Top5 更可能来自土壤水热、辐射、温度/积温、湍流/稳定度**；但必须以实际排序为准，不能预写名单。
3. **事件窗口 72/72 有效（站点降水）**；其他变量的事件窗口有效率需在 Q1 结果中报告，不能一概说“72/72 全有效”。
4. **单事件不能给因果**；Top5 是“事件窗口异常 + 稳定性”的排序，不是“触发原因排序”。
5. **站点 65 km 代表性**是 Q1 最大局限；论文必须把“站点尺度”和“源区尺度”分开写。

## 创新点（相对“跑个随机森林”）

1. **物理特征体系**：边界层动力、辐射、土壤水热、湍流/能量、降水/前期、天气过程/极端，六组 33 特征，每个有公式和单位。
2. **单事件关联性协议**：同季节/同时刻基线 + 稳健异常 + 循环块置换 + BH FDR + bootstrap 排名稳定性；不是“相关系数排个序”。
3. **零模型校准**：用置换分布检验“事件窗口是否真的异常”，并给出假阳性控制。
4. **证据分级**：每个特征标 `[A]`（站点观测统计）；再分析对照标 `[B]`；不把代理当因果。
5. **可反驳**：Top5 附排名区间和稳定性；如果换窗口/基线就翻，论文明确写“排序不稳定”。
6. **观测几何敏感性（可选）**：层对/土壤深度/footprint 扇区/源区方位的离散候选 + 稳定性约束；不替代主排序，见 [`Q1几何优化.md`](Q1几何优化.md)。
