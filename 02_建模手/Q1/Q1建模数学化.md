## 三、基线、异常与聚合

### 3.1 基线集 `B`

对每个 `y=2021..2026`：

1. 取 `S_y` = 8 月 11 日 00:00–9 月 10 日 23:00（2026 截断到 8 月 26 日 10:00）。
2. 删除 `E_all`（避免事件污染）。
3. 只保留小时属于 `E_pre` 的小时集合（同季节 + 同时刻）。
4. 对每个特征，剔除缺失/QC 可疑样本；要求 `n_valid(B) ≥ 0.7·n_total(B)`。

### 3.2 稳健异常（连续特征）

对特征 `j`：

```
med_j = median(X_j(t), t∈B)
mad_j = median(abs(X_j(t)-med_j), t∈B)
scale_j = 1.4826·mad_j
z_j(t) = (X_j(t)-med_j)/scale_j
```

若 `scale_j = 0`：

1. 用 `IQR_j/1.349` 替代；
2. 若仍为 0，用经验分位映射 `z_j(t)=Φ^{-1}((rank(X_j(t))-0.5)/n_B)`，截断到 `[-3.5,3.5]`。

**变换**：`Precip_1h/24h/72h`、`API` 先做 `log1p` 再算 `z`；若仍零膨胀，直接用分位映射。`WD` 不直接用角度，F03 已用 `1-cos`。

### 3.3 二值特征

```
rate_E,j = mean(I_j(t), t∈E)
rate_B,j = mean(I_j(t), t∈B)
A_j = rate_E,j - rate_B,j
D_j = sign(A_j)
```

### 3.4 窗口聚合

连续特征：

```
A_j = mean_{t∈E} abs(z_j(t))
D_j = mean_{t∈E} z_j(t)
```

二值特征按上式；`A_j` 为率差，`D_j` 为方向。

> 主窗口 `E_pre`；敏感性 `E72`、`E6`、`E_all`。`A_j` 不带方向；方向看 `D_j`。

## 四、置换零分布与显著性

### 4.1 循环块置换

对每个特征 `j`、每个 `y`：

1. 在 `S_y` 内随机选一个起始小时 `s`，使窗口 `[s, s+len(E)-1]` 完全落在 `S_y` 内。
2. 用该窗口计算 `A_j^(b)`（与真实 `E` 同样的聚合方式）。
3. 重复 `B=1000` 次，跨年汇总（每年约 167 次）。

**为什么用循环块**：保留日变化和小时自相关；不能简单逐点打乱（会破坏自相关，p 值偏小）。

### 4.2 标准化与 p 值

```
mean_null_j = mean_b A_j^(b)
sd_null_j   = sd_b A_j^(b)
A_j^std     = (A_j - mean_null_j)/sd_null_j
p_j         = (1 + #{b: A_j^(b) >= A_j})/(B+1)
```

`A_j^std` 是排序分数；`p_j` 是单侧 p 值。`BH` 校正得到 `q_j`。

### 4.3 排序与 Top5

1. **门槛**：`q_j <= 0.10`、`valid_E >= 70%`、`valid_B >= 70%`、有明确物理机制。
2. **非冗余**：对 `B` 上的特征做 Spearman 相关；`abs(ρ)>=0.85` 聚为一簇；同一簇最多保留 2 个，优先 `A_j^std` 大且物理最直接者。
3. **排序**：按 `A_j^std` 降序；取前 5。
4. **兜底**：若通过门槛的特征少于 5 个，按 `A_j^std` 补足，但标“探索性”，不能声称显著。

### 4.4 稳定性

- **年份 bootstrap**：有放回抽 6 个年份（2021–2026），重算 `med/mad/A_j`，用固定零分布 `mean_null/sd_null` 标准化，重排名；`B=500`。
- **leave-one-year-out**：依次去掉一年，重算排序；`6` 次。
- 输出：中位排名、2.5%/97.5% 排名区间、Top5 频率。
- **稳定性门槛**：Top5 频率 `>=70%` 视为稳定；否则在论文中标注“排序不稳定”。

## 五、约束条件

| 编号 | 约束 | 含义 |
|---|---|---|
| C1 | `valid_E >= 0.7` 且 `valid_B >= 0.7` | 缺测太多不参与排名 |
| C2 | `t <= t0+6h` | 不用事件后超过 6 h 的数据 |
| C3 | `B ∩ E_all = ∅` | 基线不被事件污染 |
| C4 | 不补零、不插值 | 缺测保持缺失；敏感性才做成对删除 |
| C5 | 二值阈值只用 `B` | 防止用事件窗口定阈值 |
| C6 | `z` 截断 `[-10,10]` | 防止极端值支配 |
| C7 | 同簇最多 2 个 | 防止 Top5 被同一过程占满 |
| C8 | 所有输出可追溯到脚本/hash | 满足 R9/R18 |

## 六、问题类型与复杂度

- **类型**：描述性统计 + 关联排序（不是预测、不是因果、不是优化）。
- **数据规模**：`N≈52,584` 小时，`J=33` 特征；`B` 约 3,000–4,000 样本。
- **计算量**：特征构造 `O(NJ)`；置换 `O(B·J·len(E)·Y)` ≈ `1000×33×25×6 ≈ 5×10^6` 次窗口聚合，向量化后可接受；bootstrap `500×33×6` 量级更小。
- **内存**：原始 24 CSV 约 25 MB；特征矩阵 52,584×33 约 1.7M 个数，远小于内存上限。
