## 二、V1–V12 逐项算例

### V1 first-passage

**输入**：`I=[0.2, 0.5, 1.2, 1.5]`，阈值 `1.0`，`t=0,1,2,3`。

**计算**：

- `t=0`: 0.2 <1
- `t=1`: 0.5 <1
- `t=2`: 1.2 ≥1 → 首次触发

**期望**：`T=2`（0-based；若按整点写“第 3 个时刻”）。

**常见错**：返回 1-based `3` 却未说明；把 `≥` 写成 `>`（边界值漏掉）。

---

### V2 线性分位

**输入**：`[1,2,3,4,5]`；`q=0.025/0.975`。

**计算**（线性插值，位置 `(n-1)q`）：

- `q=0.025`：位置 `4×0.025=0.1` → `1 + 0.1×(2-1)=1.1`
- `q=0.975`：位置 `4×0.975=3.9` → `4 + 0.9×(5-4)=4.9`

**期望**：`q2.5=1.1`，`q97.5=4.9`。

**常见错**：用 nearest/中点法；把 `q` 当百分位 2.5 而不是 0.025。

---

### V3 lead time

**输入**：`T_impact=10:00`，`T_warn=08:00`。

**计算**：`L=10-8=2 h`。

**期望**：`L=2.0 h`。

**常见错**：未预警时记 0；迟报记正数。

---

### V4 删失

**输入**：`[1,2,3,4,∞]`。

**计算**：

- `p_inf=1/5=0.2`
- 有限值 `[1,2,3,4]`；`q0.025` 位置 `3×0.025=0.075` → `1+0.075=1.075`
- `p_inf=0.2>0.025` → 上界 `∞`

**期望**：`p_inf=0.2`，下界 `1.075`，上界 `∞`，中位 `2.5`。

**常见错**：把 `∞` 丢掉只对 `[1,2,3,4]` 取 97.5 分位给有限上界；把 `p_inf` 当 0。

---

### V5 代理覆盖率

**输入**：100 个测试样本，95 个落入区间。

**计算**：`π_proxy=95/100=0.95`。

**参考 Wilson 95% CI**：`[0.8882, 0.9785]`（可选，不要求逐位一致）。

**期望**：`0.95`。

**常见错**：把代理 coverage 写成“事件级 95%”；只报点估计不报 CI/区间宽度。

---

### V6 预警规则

**输入**：`t0=0/1/2` 的 `P(T_impact≤t0+6h)=0.4/0.7/0.92`；`p_warn=0.9`。

**计算**：

- `t0=0`: 0.4 <0.9
- `t0=1`: 0.7 <0.9
- `t0=2`: 0.92 ≥0.9 → 首次达标

**期望**：`T_warn=2`（0-based 小时）。

**常见错**：用 `>` 而不是 `≥`；用事件后信息算 CDF。

---

### V7 竞争风险

**输入**：`T_rain=∞`，`T_ice=10.5`，`T_glof=∞`。

**计算**：`min(∞,10.5,∞)=10.5`。

**期望**：`T_trigger=10.5`；先触发分支 `ice`。

**常见错**：把 `∞` 当 0；只算降雨分支。

---

### V8 空间预警半径

**输入**：`D_arrival=20 km`，`buffer=5 km`。

**计算**：`R_warn=20+5=25 km`。

**期望**：`25.0 km`。

**常见错**：把 `D_arrival` 与 `D_impact` 混写；把 buffer 当影响范围。

---

### V9 方差分解

**输入**：`Var_driver=0.8`，`Var_total=1.0`。

**计算**：`share=0.8/1.0=0.8`。

**期望**：`0.8`（80%）。

**常见错**：分母用 `Var_total-Var_driver`；分组不互斥。

---

### V10 共形分位

**输入**：校准分数 `[1,2,3,4,5]`，`n=5`，`α=0.05`。

**计算**：

```
level = ceil((n+1)(1-α))/n = ceil(6×0.95)/5 = ceil(5.7)/5 = 6/5 = 1.2
```

`level≥1` → 取最大分数 `q_conf=5`。

**期望**：`q_conf=5.0`，`level=1.2`；测试 `Ŷ=8` → 区间 `[3,13]`。

**常见错**：用 `ceil(n(1-α))/n`；`level>1` 时仍插值外推。

---

### V11 API72

**输入**：`P=[1,2,3]`，`k=0.9`，最近时刻权重最大。

**计算**：

```
API = 3×0.9^0 + 2×0.9^1 + 1×0.9^2
    = 3 + 1.8 + 0.81 = 5.61
```

**期望**：`5.61`。

**常见错**：权重方向反了（`1×1 + 2×0.9 + 3×0.81`）；用 `k=1`。

---

### V12 区间宽度

**输入**：`q2.5=1.1`，`q97.5=4.9`。

**计算**：`W=4.9-1.1=3.8`。

**期望**：`3.8`。

**常见错**：用 `q97.5+q2.5`；删失时仍给有限宽度。
