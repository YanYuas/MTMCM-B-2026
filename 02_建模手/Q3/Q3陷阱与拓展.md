## 一、工程陷阱 T1–T15

| 编号 | 陷阱 | 现象 | 对策 |
|---|---|---|---|
| T1 | 时区混用 | UTC/北京时/LST 混用 | 全部转 Asia/Shanghai；记录原时区 |
| T2 | 事件 10:30 与整点 | 把 10:30 当 10:00 | 区间以小时/分钟说明；不假装分钟精度 |
| T3 | CHIRPS 日值当小时 | 日雨量直接进 1h 强度 | 只作日尺度；小时用站点/再分析 |
| T4 | 预报回填历史 | 用 2026-10-24 forecast 算 2026-08-26 | 检查 forecast 起始；历史不用 |
| T5 | 时间戳重复/缺测 | 重采样后重复 | 去重；记录插值 |
| T6 | 单位混用 | mm/h vs mm/day | 统一 mm/h；CHIRPS 日值转换 |
| T7 | `∞` 进均值/方差 | NaN/Inf 传播 | 只对有限值算；`p_inf` 单独 |
| T8 | 分位插值不一致 | 端点差 0.1 h | 固定线性分位；报告 |
| T9 | 集合种子 | 结果不可复现 | 固定 seed；记录 |
| T10 | 预警偷看未来 | `T_warn` 用了事件后数据 | 每个 t0 只用 ≤t0 信息 |
| T11 | 空间单位 | km/m 混用 | 统一 km；主沟 49.622 km |
| T12 | Q4 未完成 | 把情景 `T_travel` 当实测 | 标 `[C]`；Q4 回填 |
| T13 | 代理目标泄漏 | 用未来值构造特征 | 严格时序切分 |
| T14 | 共形交换性 | 时间自相关 | 分块/年份分割；标 B |
| T15 | 图中文 mathtext | 方框 | 中文不进 `$...$` |

## 二、边界情形

| 情形 | 处理 |
|---|---|
| 全窗口不触发 | `T_trigger=∞`；报 `p_inf`；不强行给有限区间 |
| 三分支同时有限 | 取最小；记录并列/先触发频率 |
| `p_inf>2.5%` | 95% 上界 `∞`；报告 |
| 未预警 | `T_warn=∞`；`L=NA`；漏报单独计 |
| 迟报 | `T_warn>T_impact`；`L<0`；不能当正 lead time |
| 事件在窗口外 | 不评估；不补标签 |
| 驱动缺测 | 该场景跳过/降权；报告有效场景数 |
| 校准集太小 | 共形 `q_conf` 不稳定；报告 n |
| 代理覆盖率 100% | 区间过宽；报告宽度，不只报 coverage |
| 2026/2025 非降雨 | 降雨分支 `∞` 是正确负控制 |
| Q4 未完成 | 空间/传播用情景区间；标 C |
| 冰崩/GLOF 无检测 | 分支 `∞`；不预测释放 |

## 三、边界情形与论文写法

| 情形 | 写法 |
|---|---|
| `p_inf` 高 | “删失比例高；上界为 ∞；不伪造有限区间” |
| 预警规则敏感 | “H_warn/p_warn 敏感；不写最优” |
| 代理 coverage 高但区间宽 | “coverage 高但区间宽；代理≠事件级” |
| 事件级 coverage 不可识别 | “只报案例包含性 2/2” |
| 冰崩/GLOF 情景 | “条件情景/监测触发，不是气象预测” |
| Q4 未完成 | “空间/传播为情景区间，Q4 回填” |
| 阈值未标定 | “文献/情景区间；不写标定值” |

## 四、拓展方向

1. **事件目录**：≥5 个可信事件日期后，启用 B（生存/共形事件级 coverage）。
2. **源区监测**：InSAR/视频/地震/湖位，把冰崩/GLOF 从情景变成可预警。
3. **冰湖编目**：湖面积/坝高/自由board，建立 GLOF 判据。
4. **Q4 耦合**：`T_travel/D_arrival/D_impact` 从 Q4 回填，收窄空间范围。
5. **历史预报存档**：用真实历史预报做 hindcast，避免再分析替代。
6. **决策价值**：把 `H_warn/p_warn` 与成本-损失函数结合，给预警策略建议。
7. **集合校准**：若有更多事件，做 rank histogram/CRPS 校准。

## 五、实现检查清单

- [ ] 所有时间转 Asia/Shanghai；事件 10:30 保留
- [ ] 历史不用 forecast；forecast 单独目录
- [ ] 驱动单位统一 mm/h；CHIRPS 日值不冒充小时
- [ ] `∞` 不进均值/方差；`p_inf` 单独
- [ ] 分位线性插值；seed 固定
- [ ] 预警时间线每个 t0 只用过去
- [ ] 事件级/代理/设计 coverage 三列分开
- [ ] 空间 `D_arrival/D_impact/R_warn` 三行
- [ ] 2026/2025 非降雨负控制通过
- [ ] 输出无“概率/置信度”误用
- [ ] 图/表数字来自脚本；无硬编码
