## 二、驱动与降雨分支

### 2.1 驱动集合

`d ∈ {station, ERA5, NASA, CHIRPS}`；前三个为小时/日值，CHIRPS 为日值（0.05°）。日值驱动在小时内按均匀分配或事件窗口累计，论文写清插值/聚合规则。

### 2.2 降雨触发指标

```
API_d(t) = Σ_{i=0}^{71} k^i P_d(t-i),   k=0.9
m(t)     = clip( VWC_0.4(t)/φ, 0, 1 ),  φ=0.40（情景）
I_rain(t)= max( P1h(t)/I_c(1), API_d(t)/API_c, m(t)/m_cr )
```

- `I_c(1)=a`（D=1 h）；`a=10`、`b=0.5` 为文献/情景值（Q2）。
- `API_c` 为情景阈值（建议 60–120 mm）；`m_cr` 用 Q2 公式，参数区间见公式表。
- 若 `m_cr<=0` 或 `>1`：`m/m_cr` 分支禁用（Q2 判读）。
- 触发：

```
T_rain(d,θ) = inf{ t : I_rain(t) ≥ 1 }
```

若全窗口 `I_rain<1`：`T_rain=∞`（删失）。

### 2.3 2026/2025 负控制

- 2026：站点 72 h 0.0 mm；CHIRPS 事件区 23.24 mm；`P1h` 远低于 10 mm/h，`API/API_c<1`，`m/m_cr<1` → `T_rain=∞`。
- 2025：站点 0.0 mm；CHIRPS 事件区 11.81 mm → `T_rain=∞`。
- 这不是“模型失败”，而是正确识别“非降雨触发”。

## 三、冰崩/GLOF 分支（情景/监测）

### 3.1 为什么不能用气象数据“预测释放”

TPDC-04 只有冰厚/速度/地形（2014–2024 气候态），没有源区连续气象/失稳前兆；站点距源区远。用台站气温/降水去“预测”冰崩释放是伪因果。因此：

- **冰崩/GLOF 分支是条件情景**：给定监测/事件目录的释放检测时刻 `T_detect`，触发时间在检测前 `τ` 内；
- 标签 `[C]`；不是从气象驱动预测释放；
- 前瞻预警需要源区监测（InSAR/地震/视频/湖位），当前附件不具备。

### 3.2 冰崩分支

```
T_ice = T_detect - τ_ice,   τ_ice ~ Uniform(0, Δ_ice)
```

`Δ_ice=3 h`（情景）；若 `T_detect` 未知/未检测：`T_ice=∞`。

可选（不作为主结果）：源区正积温/融化指标

```
PDD(t) = Σ max(T_source(t)-T0, 0),  T_source = T_grid + Γ(z_source-z_grid)
```

`Γ=6.5°C/km`；`T0=0°C`；阈值 `PDD_c` 情景。仅作“若有源区温度”的展望，不用于 2026 事后解释。

### 3.3 GLOF 分支

```
T_glof = T_detect - τ_glof,  τ_glof ~ Uniform(0, Δ_glof)
```

`Δ_glof=6 h`；无冰湖编目/湖位/坝高 → 只作情景；若未检测：`T_glof=∞`。

## 四、竞争风险与删失

```
T_trigger = min(T_rain, T_ice, T_glof)
```

- 若三分支全 `∞`：`T_trigger=∞`（删失）；记录 `P(no trigger)`。
- 若多个分支有限：取最小；记录“哪个分支先触发”的频率。
- `T_impact = T_trigger + T_travel`；`T_travel~Uniform(0.5,3.0) h`（主沟 49.622 km，速度 5–15 m/s 的量级；Q4 回填后替换）。
- 删失不能丢：`P(no trigger)` 若 >2.5%，95% 区间上界为 `∞`，不能强行给有限上界。

## 五、集合与区间

### 5.1 集合抽样（N=2000）

| 参数 | 分布/范围 | 说明 |
|---|---|---|
| 驱动 `d` | 等权 {station, ERA5, NASA, CHIRPS} | 多源分歧；不做“最优驱动”挑选 |
| `a` | U(5,20) | I-D 参数，文献/情景 |
| `b` | U(0.3,0.7) | 同上 |
| `API_c` | U(60,120) mm | 情景 |
| `m0` | U(0.15,0.35) | 初始饱和度 |
| `c'` | U(0,20) kPa | Q2 `m_cr` |
| `φ'` | U(25,40)° | Q2 `m_cr` |
| `z` | U(0.5,3.0) m | Q2 `m_cr` |
| `γ_sat` | U(18,22) kN/m³ | Q2 `m_cr` |
| `Δ_ice` | U(1,3) h | 冰崩检测延迟 |
| `Δ_glof` | U(3,6) h | GLOF 检测延迟 |
| `T_travel` | U(0.5,3.0) h | Q4 回填前情景 |

### 5.2 区间

```
I_95(T_trigger) = [q_{0.025}, q_{0.975}]
```

- 只在有限样本上取分位；若删失比例 `p_inf>0.025`，上界记 `∞`，并报告 `p_inf`。
- 区间是**预测区间**，不是参数置信区间；首次出现时说明。
- 同时报告：中位数、IQR、区间宽度、`P(no trigger)`、分支先触发频率。

### 5.3 不确定性分解

按驱动/阈值/初始条件/释放延迟/传播时间分组，计算各组对 `Var(T_trigger)` 的贡献（方差分解或分组均值方差）；报告主导来源。不能只给一个区间宽度。

## 六、预警规则与预警时间

### 6.1 发布规则

在每个决策时刻 `t0`（小时），用当前信息 `F(t0)` 计算 `T_impact` 的预测 CDF：

```
T_warn = min{ t0 : P(T_impact ≤ t0 + H_warn | F(t0)) ≥ p_warn }
```

- `H_warn`：预警视野（建议 6 h；敏感性 1/3/6/12 h）。
- `p_warn`：决策阈值（建议 0.9；敏感性 0.8/0.9/0.95）。
- 若到事件结束仍未满足：`T_warn=∞`（漏报）。
- 预警时间：

```
L = T_impact - T_warn
```

- 若 `T_warn=∞`：`L=NA`，不能记 0。
- 若 `T_warn` 在 `T_impact` 之后：负 lead time，记“迟报”，不能当正 lead time。

### 6.2 历史案例

- 2026/2025 的 `T_ice/T_glof` 是情景锚定，不是预测；`L` 只能作“条件 lead time”案例，不写“平均预警时间”。
- 降雨分支：`T_rain=∞`，不预警是正确负控制。
- 2 个事件不能算漏报率/虚警率；只做案例时间线。

## 七、覆盖率三口径

### 7.1 事件级（不可识别）

```
π_event = (1/n_events) Σ 1[ T_event ∈ I_95 ]
```

`n_events=2`（本地）；只能报“案例包含性 2/2”，不能报 95% 覆盖率；`π_event` 不可估计。

### 7.2 代理级（可计算）

选代理 `Y`（建议 24 h 降水或 6 h 气温）；用 split conformal：

```
s_i = |Y_i - Ŷ_i|（校准集）
q   = Quantile_{ceil((n+1)(1-α))/n}(s)
I   = [Ŷ - q, Ŷ + q]
π_proxy = (1/n_test) Σ 1[Y_i ∈ I_i]
```

- `α=0.05`；报告 `π_proxy`、区间宽度、Wilson 95% CI。
- 代理覆盖率 ≠ 事件级覆盖率；论文必须分开写。

### 7.3 设计级

`π_design=0.95`（名义）；只作方法说明，不是经验覆盖率。

```

D_impact  : 流深/流速超过影响阈值的范围（Q4）
R_warn    : 预警覆盖半径 = D_arrival + buffer（或监测半径）
```

- Q4 未完成时：`D_arrival~U(20,50) km`、`D_impact~U(5,30) km`、`R_warn~U(25,55) km`；主沟 49.622 km 作为上界参考；标 `[C]`。
- 不把 Q4 情景包络写成“实测到达范围”；不把 `D_arrival` 与 `D_impact` 混成一个数。
