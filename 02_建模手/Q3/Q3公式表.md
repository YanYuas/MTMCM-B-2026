## 二、降雨分支

### F1 API72

```
API_d(t) = Σ_{i=0}^{71} k^i P_d(t-i),   k=0.9
```

### F2 饱和度

```
m(t) = clip( VWC_0.4(t)/φ, 0, 1 ),   φ=0.40（情景）
```

### F3 降雨触发指标

```
I_rain(t) = max( P1h(t)/I_c(1), API_d(t)/API_c, m(t)/m_cr )
```

- `I_c(1)=a`；`a=10`、`b=0.5` 为文献/情景。
- `API_c` 60–120 mm；`m_cr` 用 F5。
- 若 `m_cr<=0` 或 `>1`：`m/m_cr` 分支禁用。

### F4 降雨 first-passage

```
T_rain(d,θ) = inf{ t : I_rain(t) ≥ 1 }
```

无触发：`T_rain=∞`。

## 三、冰崩/GLOF 分支

### F5 冰崩

```
T_ice = T_detect - τ_ice,   τ_ice ~ U(0, Δ_ice),  Δ_ice=3 h
```

无检测：`T_ice=∞`。

### F6 GLOF

```
T_glof = T_detect - τ_glof,  τ_glof ~ U(0, Δ_glof),  Δ_glof=6 h
```

无检测：`T_glof=∞`。

> F5/F6 是**条件情景/监测触发**，不是从气象数据预测释放；标签 `[C]`。

## 四、竞争风险与删失

### F7 竞争风险

```
T_trigger = min(T_rain, T_ice, T_glof)
```

### F8 影响时间

```
T_impact = T_trigger + T_travel,   T_travel ~ U(0.5, 3.0) h
```

### F9 预警时间

```
L = T_impact - T_warn
```

未预警：`L=NA`；迟报：`L<0`，不能当正 lead time。

### F10 删失比例

```
p_inf = (1/N) Σ 1[T_trigger = ∞]
```

若 `p_inf > 0.025`，95% 区间上界记 `∞`。

## 五、集合与区间

### F11 分位

```
q_α = Quantile_α({T_trigger^(1),...,T_trigger^(N)})
```

只对有限样本取分位；`∞` 单独计。

### F12 95% 预测区间

```
I_95 = [q_{0.025}, q_{0.975}]
```

若 `p_inf>0.025`：`I_95=[q_{0.025}, ∞)`。

### F13 区间宽度

```
W = q_{0.975} - q_{0.025}
```

### F14 不确定性分解

```
Var(T_trigger) = Var_driver + Var_threshold + Var_initial + Var_release + Var_travel + Var_resid
share_g = Var_g / Var_total
```

按驱动/阈值/初始条件/释放延迟/传播时间分组；报告主导来源。

## 六、预警规则

### F15 预测 CDF

```
F_{T_impact|F(t0)}(t0+H_warn) = P(T_impact ≤ t0+H_warn | F(t0))
```

### F16 预警时刻

```
T_warn = min{ t0 : F_{T_impact|F(t0)}(t0+H_warn) ≥ p_warn }
```

`H_warn=6 h`、`p_warn=0.9` 为主值；敏感性 1/3/6/12 h、0.8/0.9/0.95。

### F17 Lead time

```
L = T_impact - T_warn
```

## 七、覆盖率

### F18 事件级覆盖率（不可识别）

```
π_event = (1/n_events) Σ 1[T_event ∈ I_95],  n_events=2
```

只能报“案例包含性”，不能报 95% 覆盖率。

### F19 共形分位

```
q_conf = Quantile_{ceil((n+1)(1-α))/n}(s_i),  s_i=|Y_i-Ŷ_i|
```

`α=0.05`；`n` 为校准集大小。

### F20 共形区间

```
I_i = [Ŷ_i - q_conf, Ŷ_i + q_conf]
```

### F21 代理覆盖率

```
π_proxy = (1/n_test) Σ 1[Y_i ∈ I_i]
```

报告 Wilson 95% CI；代理 ≠ 事件级。

## 八、空间范围

### F22 到达距离

```
D_arrival = max{ s : flow depth/velocity > 0 along channel }   （Q4）
```

### F23 影响范围

```
D_impact = max{ s : h(s) ≥ h_c 或 v(s) ≥ v_c }   （Q4）
```

### F24 预警半径

```
R_warn = D_arrival + buffer   （buffer=5 km 情景）
```
