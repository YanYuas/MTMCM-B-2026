## 核心方法论模板

### 模板1：题设逐词点透法（用在全解总览开头）

**目的**：展示对题目的深刻理解。

```markdown
## 题设逐词点透

> "（粘贴题目原文）"

| 词 | 字面意思 | 点透（为什么重要） |
|---|---|---|
| "XX" | 字面含义 | 更深层含义 → 这决定了建模方向是... |

**点透结论**：（一句话总结本题本质和隐藏决策）
```

### 模板2：一句话定位

```
**Q? = [问题本质] + [次级目标]。[数据范围/特点]。[复杂度]。解法 = [核心算法]，配[辅助技巧] + [验证方法] + [防坑措施]。**
```

### 模板3：假设系统化 H1–H4（每条带"若违背"后果）

```markdown
### H1 【类别】假设
| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| H1.1 | | | |
```

**关键原则**：每条假设必须写"若违背的后果"。

### 模板4：陷阱分级 T+M

- **T 系列（工程级）**：实现时容易踩的坑（口径/数值/边界）
- **M 系列（模型级）**：建模思路本身的陷阱（更深层）

```markdown
### M1. 陷阱名称
- **现象**：
- **后果**：
- **对策**：
- **论文卖点**：
```

### 模板5：三层下界

1. **平凡下界**：太松，但必须写
2. **理论下界**：太紧，完美情形才可达
3. **工程下界**：工程可用，"近最优"论证挂在这上面

### 模板6：不确定量清单（元断言）
