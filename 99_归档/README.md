# 归档

> 版本：v0.1.0 | 日期：【日期】
> 用途：历史版本、废弃方案、中间临时文件的归档。**只做整理，不删除任何东西。**

---

## 目录

```
99_归档/
├── README.md                 ← 本文件
├── 历史版本/                 旧版本文档、旧版代码
├── 废弃方案/                 被否决的思路、弃用的图、废弃的代码
└── 中间临时/                 中间产物、临时文件、OCR中间文件
```

---

## 归档规则

1. **只做整理，不删除任何东西。** 所有文件都有价值，哪怕是失败的尝试。
2. 旧版本进 `历史版本/`，文件名加日期和版本号，如 `Q1正稿_2026-09-11_v0.9.md`。
3. 废弃方案进 `废弃方案/`，文件头写明"已废弃，原因：…，替代方案：…"。
4. 被否决的思路同时登记到 `02_建模手/实践反馈融入.md` 红线台账。
5. 弃用图必须从 `03_编程手/图表库/` 和 `04_论文手/Q?/配图/` 移出，进本目录。
6. 中间临时文件（OCR、缓存、__pycache__）进 `中间临时/`，或按 .gitignore 排除。

---

## 为什么不删除

- 失败的尝试记录了"什么不可行"，比成功更有价值。
- 旧版本可以回溯"为什么改"，避免重复踩坑。
- 废弃方案可能在后续问或下一场比赛中重新启用。
- 数模竞赛的经验沉淀，就是从这些"没用的"文件里来的。
