## 官方硬约束（2026 大数据竞赛）

- 论文统一提交 **PDF**，文件名 `B+队号.pdf`（以赛氪上传页/组委会最终口径为准）。
- 承诺书每个队员手写或电子签名，生成 PDF/图片，文件名 `B+队号+承诺书`。
- 支撑材料打包为 `B+队号+附件.rar/zip`，含程序、数据（赛题原始数据除外）、结果、`AI工具使用详情说明.pdf`。
- **正文 ≤30 页，附录不限**；首页题目/摘要/关键词，第 2 页目录，正文起页码；无页眉、无身份信息。
- 赛道必须为 **B**；赛道与内容不符取消评奖资格。
- AI 使用声明放在**参考文献之后**；核心建模/算法/求解/分析由队员完成。

## 提交前检查清单

- [ ] 格式符合官方模板（首页/目录/页码/无页眉）
- [ ] **正文 ≤30 页**（内部预算 28 页），附录不计入
- [ ] 摘要含方法+关键数字，关键词 3–5 个

- [ ] 图表编号与 `04_论文手/*/配图清单.md` 一致
- [ ] 图真正嵌入（解包 docx 核 `<w:drawing>` 和 media 数量）
- [ ] 图注段前一段即图片段
- [ ] 参考文献格式统一，全部引用出现

- [ ] 创新点集中提炼（3–5 条）

- [ ] AI 声明在参考文献之后，内容完整

### 程序包
