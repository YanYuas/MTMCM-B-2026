# 3D 推演沙盘方案（Q2/Q3/Q4 联合）

> 版本：v0.1 方案 | 日期：2026-10-24 | 状态：待定技术栈/数据接入
> 目标：把 Q2 易发性、Q3 触发/预警、Q4 传播仿真接到一个可交互的 3D 沙盘里，参数一变就能看到“地形—水源—释放—传播—影响”的响应。

---

## 0. 先说清楚“真实”的边界

当前数据能支撑 **山谷尺度** 的真实地形推演，不能直接做“街道级数字孪生”：

| 能真实反映 | 当前数据 |
|---|---|
| 地形/坡度/沟道 | 30 m DEM、坡度、D8 汇流、主流路 49.622 km |
| 冰川源区 | TPDC-04 冰厚/速度/掩膜（气候态，不是实时） |
| 土地覆盖 | 2023 期 30 m，编码 1–10 无图例 |
| 人口背景 | 县级 17,536/16,155，不是建筑级 |
| 降雨/土壤水 | 站点小时 + ERA5/NASA/CHIRPS；事件窗口 |
| 触发/预警 | Q3 集合、竞争风险、代理共形 |

**缺的**：建筑轮廓、道路、POI、正射影像、高分辨率 DEM（5–10 m）、实时雷达/雨量、冰湖编目。没有这些，沙盘能到“沟谷—口岸—堆积扇”尺度，不能到“每栋楼”。

物理核心建议用 Q4 的 **2D 深度平均 HLL + Voellmy + 密度**；3D 是它的可视化层，不是另一套 3D CFD。若要做真 3D 流体/颗粒，需要 OpenFOAM/CFDEM/GPU 求解器，周期和算力完全不是一个量级。

## 1. 三种技术栈（需要你选）

| 方案 | 适合 | 优点 | 代价 | 推荐 |
|---|---|---|---|---|
| **A. Web 3D：Three.js + Python/FastAPI** | 山谷尺度、交互参数、快速迭代 | 本地 DEM、无需许可、浏览器直接看、易分享 | 视觉不如游戏引擎；建筑级资产弱 | ⭐ 首选 |
| **B. CesiumJS + 3D Tiles** | 真实经纬度、全球地形/影像 | 地理坐标最正规，可叠影像/倾斜摄影 | 需要 Cesium Ion token 或本地 3D Tiles；流场表达弱 | 需要“地图级”时选 |
| **C. Unreal Engine 5 + Cesium for Unreal / Pixel Streaming** | 游戏级画面、建筑/道路、粒子 | 视觉最强，适合汇报/演示 | 需要 GPU 服务器、资产制作、集成周期长 | 只有明确要“电影级”才选 |
| **D. PyVista/VTK 桌面** | 科研分析、剖面/等值面 | 科学可视化强，Python 原生 | 不是“沙盘”，交互/分享弱 | 作为离线验证工具 |

**我的建议：A 先做 v0.1，物理核心复用 Q4；如果之后需要“地图级真实影像”，再加 Cesium；Unreal 只在有 GPU 服务器和建筑/道路资产时启动。**

## 2. 系统结构

```
数据层
  DEM/坡度/汇流/沟道 (GeoTIFF)
  冰川掩膜/冰厚/速度 (GeoTIFF)
  土地覆盖/人口/事件目录 (GeoTIFF/CSV/GeoJSON)
        │
        ▼
物理层（Python）
  Q4 2D HLL + Voellmy + 干湿 + 质量收支
  Q3 触发集合/竞争风险/预警时间线
  Q2 相对易发性 S（底图，不是概率）
        │  输出 frames: h(x,y,t), |u|(x,y,t), b_dep(x,y)
        ▼
服务层
  FastAPI：/scenario /run /frames /status
  或离线导出 JSON/PNG 帧
        │
        ▼
3D 层（Three.js）
  地形 mesh（30 m DEM，顶点色=高程/坡度）
  主沟 ribbon、冰川源区、口岸/堆积扇 marker
  灾害面（h/u 动态纹理或抬升 mesh）
  预警时间线、参数面板、图层开关、剖面
```

## 4. 沙盘要做的交互

1. **场景选择**：2026 冰崩链 / 2025 GLOF / 2002 区域类比 / 自定义。
2. **参数面板**：
   - 释放体积 `V0`（1e5–1e6 m³，不能拿 0.319 km³ 总冰量）；
   - 密度 `ρ`、Voellmy `μ/ξ`、源区面积/初水位；
   - 降雨 `P1h/API72`、土壤水 `VWC`、`m_cr`；
   - 网格 30/60/90 m、CFL、模拟时长。
3. **时间轴**：播放/暂停/拖动；显示 `t_arr`、`D_impact`、`h_max`、`b_dep`。
4. **图层**：地形/坡度/土地覆盖/冰川/沟道/易发性 `S`/灾害面/预警圈/聚落。
5. **剖面**：沿主沟纵剖面显示水位/流速/堆积厚度。
6. **预警时间线**：Q3 的 `T_warn`、lead 中位/区间、分支频率；明确“条件预测区间，不是概率”。
7. **验证角标**：Q4 V1–V12、质量守恒、Ritter 误差、网格收敛；未通过时红标，不允许用动画代替验证。
8. **导出**：当前帧 PNG、短视频、场景 JSON、参数/结果表。

## 5. 分阶段

### P0（1–2 天）v0.1 可视化骨架
- 导出 DEM 高度场（降采样 4×，约 45 万顶点以内）；
- Three.js 地形 + 主沟 + 冰川源区 + 口岸/事件 marker；
- 用 Q4 基线参数生成 **预计算帧**（先 1D 纵剖面/简化波前，标“可视化预览，待 Q4 求解器替换”）；
- 时间轴/图层/参数只读展示。

### P1（3–5 天）物理接入
- 把 Q4 2D HLL/Voellmy 求解器落到 `03_编程手/Q4/源代码/`；
- 跑 V1–V12/A1–A12；质量守恒/零动量/Ritter/网格收敛；
- 输出 `h/u/b_dep` 帧，FastAPI 异步任务；
- 沙盘接真实帧，参数可调，重跑一个场景 <2 min（30 m 走廊）。

### P2（1 周）真实场景增强
- 建筑/道路/影像/人口网格；
- 12 组 Q4 情景 + Q3 集合预警；
- 导出报告/视频；可选 Cesium/Unreal。
