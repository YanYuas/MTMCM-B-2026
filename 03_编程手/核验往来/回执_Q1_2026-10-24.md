## 二、A6 未通过的诊断：不是排序逻辑坏了

原始 A6 的注入方式：`z_E = z_E + 3`（在 E_pre 的 z 上加 3），再算 `A=mean(abs(z))`。这有两个问题：

1. **负异常特征**：若 E_pre 的 z 本身为负，加 3 会让 `abs(z)` 变小，不是“+3σ 异常”。  
   - F05 `ri_bulk_2_20`：`D=-2.157`，median rank 8 → 0 命中；
   - F03 `wd_shear_2_20`：`D=-1.358`，median rank 2 → 0 命中；
   - F28 `api_72h`：`D=-0.674`，median rank 15 → 0 命中。
2. **Top1 过严 + 共线**：即使注入有效，相关特征可能排第一。  
   - F13 `vwc_40`：`D=+1.619`，median rank 2 → 0 命中（与 F14 `vwc_storage_0_40` 共线）；
   - F24 `precip_24h`：`D=0`，median rank 3 → 0 命中（与 F25 `precip_72h`/F30 `p1h_p99` 相关）。

> 所以 78% 不能直接判“Q1 排序逻辑不可用”；它是**注入协议 + Top1 严格性 + 共线**的混合结果。原 A6 保留为“未通过”记录，不覆盖。

## 三、A6r 校正复测（已独立试跑，仍未通过）

**目标**：检验“已知 +3σ 正异常能否被找回”，不是检验“负异常加 3 后是否变大”。

**注入方式（推荐 1）**：

1. **置位法（推荐）**：对目标特征，把 E_pre 的 `z` 设为 `+3`（等价于 `X_E = med_B + 3·scale_B`）；再算 `A/A_std`。
2. **原始变量法**：`X_E = X_E + 3·scale_B`，再重算 `z/A/A_std`；对降水/API 先在 `log1p` 空间做。

**独立试跑结果（2026-10-24，建模手脚本）**：

- A6r 置位法：**66% Top1、80% Top3、66% 同簇 Top1**；中位排名 1；**仍 <90% Top1，未通过**。
- 原因：固定 `+3 z` 不是“固定标准化效应”；不同特征 null SD 不同，`A_std=3/sd_null` 对高方差特征只有 ~1–2，Top1 无法保证。A6 的 Top1 验收对异质 null 方差不公平。
- **结论：不再迭代 A6/A6r。** A6 原测与 A6r 都保留为失败记录；论文写“方法验证未通过/测试设计限制”，不写“方法已验证”。
