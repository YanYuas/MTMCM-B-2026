# 数据卡：NASA POWER 逐小时气象（MERRA-2 / POWER）

> 数据治理层生成；来源配置 `config/governance.json`；来源 ID `nasa_power`。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 类型 | api_json |
| URL | https://power.larc.nasa.gov/api/temporal/hourly/point |
| DOI | — |
| 访问日期 | 2026-10-24 |
| 抓取状态 | HTTP 200 |
| 覆盖/规模 | 216 行；2026-08-20T00:00:00 → 2026-08-28T23:00:00 |
| 对应问题 | Q1、Q3 |

## 2. 角色与尺度

- **角色**：Q1/Q3 再分析交叉核对
- **时间**：1 h；2026-08-20 至 2026-08-28；LST
- **空间**：MERRA-2/POWER 网格；请求点海拔约 4995 m
- **坐标系**：EPSG:4326
- **许可**：NASA POWER 公开数据条款

## 3. 能支持 / 不能支持

**能支持：**
- 降水/温度/湿度/风速/辐射的独立再分析对照
- 与 Open-Meteo 做一致性检查
- Q3 驱动扰动

**不能支持：**
- 站点实测
- 与站点同海拔的代表性
- 单独判定触发

## 4. 质量标记

- 再分析≠实测
- 网格海拔 4995 m 与站点 4140 m 差约 855 m
- 时间标准为 LST，需与 UTC+8 对齐

## 5. 不确定性传导

Q1 用两套再分析做一致性/分歧分析；Q3 将分歧作为驱动不确定性。

## 6. 风险

- **时间泄漏风险**：低：历史再分析；注意时间标准转换。
- **虚假精度风险**：高：海拔差 855 m，温度/降水代表性误差大。

## 7. 复现

```powershell
python -m mtmcm_data fetch nasa_power
python -m mtmcm_data validate
```
