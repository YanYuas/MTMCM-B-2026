# 数据卡：Open-Meteo 历史天气（ERA5 再分析）

> 数据治理层生成；来源配置 `config/governance.json`；来源 ID `open_meteo_archive`。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 类型 | api_json |
| URL | https://archive-api.open-meteo.com/v1/archive |
| DOI | — |
| 访问日期 | 2026-10-24 |
| 抓取状态 | HTTP 200 |
| 覆盖/规模 | 216 行；2026-08-20T00:00 → 2026-08-28T23:00 |
| 对应问题 | Q1、Q2、Q3 |

## 2. 角色与尺度

- **角色**：Q1/Q2/Q3 事件窗口再分析气象对照
- **时间**：1 h；2026-08-20 至 2026-08-28；Asia/Shanghai
- **空间**：约 0.25° 网格；请求点海拔约 4138 m
- **坐标系**：EPSG:4326
- **许可**：Open-Meteo 公开 API 条款（非商业/注明来源）

## 3. 能支持 / 不能支持

**能支持：**
- 事件窗口降水/温度/土壤湿度/辐射的再分析对照
- 与站点观测做空间代表性比较
- Q3 驱动变量集合扰动的输入

**不能支持：**
- 站点实测
- 源区高海拔局地降水真值
- 替代冰崩/泥石流发生记录

## 4. 质量标记

- 再分析≠实测
- 网格海拔 4138 m 与站点 4140 m 接近，但空间代表性仍不同
- 降水为网格平均，不能解释沟道尺度

## 5. 不确定性传导

Q1 用多源对照而非单一真值；Q3 把再分析作为驱动扰动源，报告区间而非点值。

## 6. 风险

- **时间泄漏风险**：低—中：历史再分析可用；预报接口不能回填历史事件。
- **虚假精度风险**：中：0.25° 网格对 65 km 尺度仍偏粗。

## 7. 复现

```powershell
python -m mtmcm_data fetch open_meteo_archive
python -m mtmcm_data validate
```
