# 数据卡（Data Cards）

> 由 `python -m mtmcm_data governance` 生成，每来源一张。
> 用途：论文“数据来源与角色表”、支撑材料、交接给建模手/论文手时，快速说清“这数据能做什么、不能做什么、质量如何进入不确定性”。

每张卡包含：

1. 基本信息：URL、DOI、访问日期、抓取状态、覆盖/规模、对应问题；
2. 角色与尺度：时间/空间分辨率、坐标系、许可；
3. 能支持 / 不能支持；
4. 质量标记；
5. 不确定性传导；
6. 风险（时间泄漏、虚假精度）；
7. 复现命令。

治理配置在 `config/governance.json`；总报告在 `data/reports/data_governance.md`。
