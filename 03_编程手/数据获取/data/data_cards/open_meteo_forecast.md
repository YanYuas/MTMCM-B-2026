# 数据卡：Open-Meteo 天气预报（业务预报接口）

> 数据治理层生成；来源配置 `config/governance.json`；来源 ID `open_meteo_forecast`。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 类型 | api_json |
| URL | https://api.open-meteo.com/v1/forecast |
| DOI | — |
| 访问日期 | 2026-10-24 |
| 抓取状态 | HTTP 200 |
| 覆盖/规模 | 72 行；2026-10-24T00:00 → 2026-10-26T23:00 |
| 对应问题 | Q3 |

## 2. 角色与尺度

- **角色**：Q3 未来 72 h 预报接口演示
- **时间**：逐小时，未来 3 天；Asia/Shanghai
- **空间**：约 0.25° 网格；请求点海拔约 4138 m
- **坐标系**：EPSG:4326
- **许可**：Open-Meteo 公开 API 条款

## 3. 能支持 / 不能支持

**能支持：**
- 演示预报接口
- 构造未来驱动情景
- 预警提前量的接口验证

**不能支持：**
- 历史事件复盘实测
- 事件级 95% 覆盖率的验证样本
- 替代源区观测

## 4. 质量标记

- 预报不是实测
- 预报时效/误差随 Lead Time 增长
- 接口每次调用结果会变

## 5. 不确定性传导

Q3 必须区分‘预报驱动’与‘观测驱动’；预报误差要进入区间。

## 6. 风险

- **时间泄漏风险**：高：若把当前预报当历史事件输入，就是时间泄漏。
- **虚假精度风险**：中—高：预报误差 + 网格代表性。

## 7. 复现

```powershell
python -m mtmcm_data fetch open_meteo_forecast
python -m mtmcm_data validate
```
