## 这是什么

这是一套**经过实战检验的数模竞赛协作模板**，来自 2026 高教社杯（国赛）B题 74 小时完整实战的复盘。它不是空泛的"建议"，而是把我们踩过的 21 个坑、验证有效的 9 大机制、4 道质量门、25 条红线，全部固化成了可直接套用的目录结构和空白文档。

**核心理念**：
- 三手分工（建模手/编程手/论文手）+ 总控，各司其职。
- 移交—反馈—闭环，编程手是建模正确性的第一道独立检验。
- 权威数字表，全队唯一数字源。
- 只做整理，不删除任何东西。
- 所有结论由队员逐条复核。

## 怎么用（3 步开新仓）

### 第 1 步：复制本目录

把 `_模板_新比赛起步包/` 整个复制到新仓库根目录，去掉 `_模板_新比赛起步包` 这层外壳，让 `00_任务总控/` 等 8 大目录直接在仓库根。

```
新仓库/
├── 00_任务总控/
├── 01_背景研究/
├── 02_建模手/
├── 03_编程手/
├── 04_论文手/
├── 05_辅助文档/
├── 06_交付物/
├── 99_归档/
├── README.md                 ← 本文件（改写成新比赛的说明）
├── 红线清单.md                ← 开赛前全队读一遍
└── 快速开始清单.md            ← 开赛后 1 小时内做完
```

### 第 2 步：10 分钟初始化

按 `快速开始清单.md` 逐项完成：
- 填 `00_任务总控/00_核心文档/任务说明.md`（题目、分工、时间、约束）
- 建 Git 仓库，配 `.gitignore`
- 全队读 `红线清单.md`
- 各角色读自己目录的 README

### 第 3 步：按时间节奏推进

参考 `00_任务总控/00_核心文档/任务说明.md` 的时间安排表，各角色按自己目录的 README 和模板文件推进。

## 各角色快速上手指南

### 建模手
1. 读 `02_建模手/建模手总纲.md`（职责、纪律、流程）
2. 读 `02_建模手/每问建模九件套模板.md`（9 个文件怎么写）
3. 每问开始时，复制 `02_建模手/_九件套空白文件/` 到 `Q?/`，改名后填写
4. 完成后写 `00-移交说明.md`，含验证题答案，移交编程手
5. 收到反馈后独立复算，更新权威数字表和红线台账

### 编程手
1. 读 `03_编程手/README.md`（10 条铁律）
2. 读 `03_编程手/编程手工具大全.md`
3. 每问开始时，复制 `03_编程手/_每问模板/` 到 `Q?/`
4. 先读建模手移交说明，跑验证题，再写代码
5. 有理论问题写反馈，不自行改模型
6. 每步代码写【思路】注释

### 论文手
1. 读 `04_论文手/README.md`（10 条铁律）
2. 读 `04_论文手/论文手工具大全.md`
3. 每问开始时，复制 `04_论文手/_每问模板/` 到 `Q?/`
4. 先写组织方案（参考论文映射），再写正稿
5. 数字只引权威数字表，未冻结标【待填】
6. 写作前必读红线台账

### 总控
1. 开赛后 1 小时内填完任务说明
2. 维护权威数字表（唯一数字源）
3. 每批次刷新整体统筹规划和进度看板
4. 巡查回填，发现数据冲突立即列清单
5. 交付前跑提交检查清单
