## 使用顺序

1. 先读 `格式与规范/README.md`，确认提交硬约束。
2. 题目原文与数据以 `题目附件/` 为准；数据附件不入 Git，保留本地。
3. 参考论文只看结构、方法和证据组织，不抄数字、不照搬篇幅。

---

## 优秀论文参考方法

1. 找与本题**方法相近**的优秀论文（如优化题找优化题的国一论文）。
2. 重点看：**问题分析怎么写、模型假设怎么写、算法怎么描述、实验怎么设计、创新点怎么提炼**。
3. 把可借鉴的结构映射到论文组织方案（见 `04_论文手/Q?/论文组织方案.md`）。
4. **不要抄内容**，只借鉴结构和写法。
