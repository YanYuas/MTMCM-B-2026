2. 将文件名和标题中的 QX 替换为 Q2。
3. 先写 论文组织方案.md（参考论文映射、骨架、配图清单）。
4. 再写 正稿.md（数字引权威数字表，未冻结标【待填】）。
5. 配图放 配图/，在 配图清单.md 登记。
6. 写作前必读 ../../02_建模手/实践反馈融入.md（红线）。
