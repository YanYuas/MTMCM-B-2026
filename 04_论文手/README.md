## 论文手纪律（铁律）

1. **组织方案先行**：动笔前先写 `论文组织方案.md`（参考论文映射→骨架→配图清单→理论实践差距）。
2. **数值只引权威数字表**，不自己造数字；未冻结的数字标【待填】。
3. **图号与配图清单一致**，图真正嵌入（交付前解包 docx 核 media）。
4. **每问参考文献都要有覆盖**，不能只集中在前两问。
5. **定理证明移附录**：正文给结论，详细证明在附录，兼顾可读性与严谨性。
6. **假设每条带"违背后果"**。
7. **创新点集中提炼**：论文定稿后单独写"主要创新点（3–5 条）"。
8. **诚实表达**：优点、局限、改进方向都写，不夸大。
9. **版本用语义化版本**：推翻结论升主、加内容升次、改错升修订。
10. **AI 使用按规定声明、如实申报**，不"去痕迹"（写"代码精简"）。

## 写作流程（每问）

```
1. 读建模手移交包 + 实践反馈融入（红线）
2. 写论文组织方案（参考论文映射、骨架、配图清单）
3. 写正稿（数字引权威数字表，未冻结标【待填】）
4. 配图（按配图清单，图来自编程手图表库）
5. 参考文献（每问都有覆盖）
6. 回填实测数字（等编程手真机/实验结果）
7. 合并全文、排版、格式检查
```
