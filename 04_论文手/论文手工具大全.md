# 论文手工具大全

> 版本：v0.1.0 | 更新：【日期】
> 用途：数模竞赛论文手常用工具、排版、公式、绘图、文献的速查指南。

---

## 一、写作工具

| 工具 | 用途 | 说明 |
|---|---|---|
| Markdown | 正文初稿 | 轻量、版本友好，最后转 Word |
| Word | 最终排版 | 按比赛格式模板 |
| LaTeX | 公式密集型论文 | 如比赛允许 |
| Typora / Obsidian | Markdown 编辑 | 实时预览 |

---

## 二、公式工具

| 工具 | 用途 |
|---|---|
| LaTeX 语法 | 公式标准写法 |
| MathType | Word 公式编辑 |
| KaTeX | Web 公式渲染 |
| 公式编号 | 统一编号，正文引用 `（式 X-Y）` |

**规范**：
- 公式居中，编号右对齐。
- 符号在第一次出现时定义。
- 重要公式加编号，行内公式不编号。

---

## 三、绘图工具

| 工具 | 用途 |
|---|---|
| matplotlib | 数据图（Python） |
| MATLAB plot | 数据图（MATLAB） |
| draw.io / Visio | 流程图、架构图 |
| PPT | 示意图、组合图 |
| Inkscape | 矢量图编辑 |
| AI 生图 | 封面/示意图（需核验） |

**规范**：
- 图的数值只能来自模型/数据。
- 图注在图下方，格式"图 X-Y 【描述】"。
- 图中文字大小与正文协调，不出现方框（中文不进 mathtext）。
- 分辨率 ≥ 300 DPI。

---

## 四、表格工具

| 工具 | 用途 |
|---|---|
| Word 表格 | 最终排版 |
| Markdown 表格 | 初稿 |
| Excel | 数据计算后粘贴 |

**规范**：
- 表注在表上方，格式"表 X-Y 【描述】"。
- 表头加粗，三线表风格。
- 数字对齐（小数点对齐）。
- 关键数字加粗或标色。

---

## 五、参考文献

| 工具 | 用途 |
|---|---|
| Zotero / EndNote | 文献管理 |
| Google Scholar | 检索 |
| 知网 / Web of Science | 中文/英文文献 |

**规范**：
- 格式按比赛要求（通常 GB/T 7714）。
- 每问都要有文献覆盖，不能只集中在前两问。
- 标注核验状态：✅已核验 / ❓待核 / ❌不可用。
- 引用在正文中标 `[1]`。

---

## 六、排版检查清单

- [ ] 正文 ≤30 页（内部预算 28 页），附录不计入正文
- [ ] 首页题目/摘要/关键词，第 2 页目录，正文起页码
- [ ] 无页眉，无答题人/学校信息
- [ ] 字体、字号、行距符合比赛模板
- [ ] 页边距、页码正确
- [ ] 摘要字数符合要求（含方法+关键数字）
- [ ] 关键词 3-5 个
- [ ] 公式编号连续，引用正确
- [ ] 图号、表号连续，图注表注格式正确
- [ ] 图真正嵌入（解包 docx 核 media 数量）
- [ ] 参考文献格式统一，引用全部出现
- [ ] 所有数字与权威数字表一致
- [ ] 无错别字、无中英文标点混用
- [ ] AI 声明（如规定）位置正确
- [ ] 队号/姓名/学校已脱敏（支撑材料）

---

## 七、AI 辅助写作规范

- AI 可用于：润色、格式转换、公式排版、语法检查。
- AI 不可用于：编造数据、编造参考文献、替代核心论证。
- 如实申报使用情况，按比赛规定提交声明。
- "去 AI 痕迹"写"代码精简（注释与命名规范化）"，不写"去痕迹"。
